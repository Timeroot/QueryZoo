\(\oplus_n\)

PARITY

Maximally hard for every measure in the zoo except parity decision trees -- hence the witness for every "$1,1$" cell.

total basic arity: $n$ bits— also: XOR, MOD_2

Description

$\oplus_n(x) = x_1 \oplus \cdots \oplus x_n$.

Formal definition

$$\oplus_n(x) = \sum_{i=1}^n x_i \bmod 2,\qquad\text{Fourier: } (-1)^{\oplus_n(x)} = \prod_{i=1}^n (-1)^{x_i}=\chi_{[n]}(x).$$

\(\deg_p(f)\) Mod-p degree \(1 \text{ if } p = 2;\ n \text{ if } p > 2\) Over $\mathbb{F}_2$ parity is the linear form $\sum_i x_i$. For odd $p$ the multilinear representation is $\tfrac12\big(1 - \prod_i(1-2x_i)\big)$, whose top coefficient $\pm 2^{n-1}$ is a unit mod $p$, so the degree jumps back to $n$. This single function is the whole content of the $\deg_p$ column.
\(\mathrm{D}^{\mu}_{\varepsilon}(f)\) Distributional query complexity \(n\) Under the uniform $\mu$, for every $\varepsilon < 1/2$ -- and since $\mathrm{D}^\mu \le \mathrm{D} = n$ for every $\mu$, the uniform distribution is simultaneously the hardest one, so no choice of $\mu$ has to be recorded alongside the value. Every leaf of a tree of depth $< n$ leaves some coordinate unqueried, and conditioned on the queried bits the parity is still uniform on $\{0,1\}$; so any such tree errs with probability exactly $1/2$ under the uniform distribution. This is the extreme point of Yao's principle: one distribution already witnesses the worst case, with no slack.
\(\mathrm{D}^{\mathrm{prod}}(f)\) Product-distribution distributional complexity \(n\) The uniform distribution is a product distribution, and $\mathrm{D}^{\mathrm{prod}} \le \mathrm{R} = n$.
