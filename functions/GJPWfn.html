\(f_{\mathrm{GJPW}}\)

Goos-Jayram-Pitassi-Watson function

Randomized analogue of GPW: $\mathrm{R}_0, \mathrm{R} = \widetilde\Omega(\deg^2)$.

total separating arity: $n$ bits

Description

The randomized-communication-vs-partition-number construction, read as a query-complexity function.

Formal definition

Tribes-List, $\mathrm{TL}$ [GJPW18, Sec. 3.1]. The input is a $k\times k$ matrix over $\Sigma = \{0,1\}\times([k]^{k-1}\cup\{\bot\})$: each cell carries a bit $m_{ij}$ and either $\bot$ or a list of $k-1$ row indices, one for every other column. Encoding a cell takes $\Theta(k\log k)$ bits, so $n = \Theta(k^3\log k)$. Again the function is defined by an unambiguous decision tree, of cost $\Theta(k\log k)$: guess a column $j$, check that all $k$ of its bits are $1$ and that some cell holds a list, read that list in full, and check that each of the $k-1$ cells it points to carries a $0$. So $\mathrm{TL}$ is the "unique all-$1$ column, certified against all others" function, and $\mathrm{UP}^{dt}(\mathrm{TL}) = \Theta(k\log k)$.

\(\mathrm{C}^0(f)\) 0-certificate complexity \(\widetilde\Theta(n^{2/3})\) putative Upper: $\mathrm{C}_0\le\mathrm{D}=\widetilde O(n^{2/3})$. Lower: take a $0$-input with exactly one all-$1$ column $c$, whose list sits in the last cell of $c$ and has at least one target carrying $1$. Every other column is refuted by a single $0$ bit, but refuting $c$ itself forces the certificate to pin the whole column -- the $k-1$ earlier pointer fields as $\bot$ plus the list itself, $\Theta(k^2\log k)=\widetilde\Theta(n^{2/3})$ bits. Fixing another column entirely to $1$ (the cheap $\Theta(k)$-bit block that works for all other columns) is not available, since no other column is all-$1$ in this input.
\(\mathrm{C}(f)\) Certificate complexity \(\widetilde\Theta(n^{2/3})\) Squeeze: $\mathrm{C}\ge\mathrm{C}_0$ and $\mathrm{C}\le\mathrm{D}$. As in \(f_{\mathrm{GPW}}\) the asymmetry is total: $\mathrm{C}_1=\widetilde O(n^{1/3})$ against a maximal $\mathrm{C}_0$.
\(\mathrm{UC}(f)\) Unambiguous certificate complexity \(\widetilde\Theta(n^{2/3})\) Squeeze: $\mathrm{C}\le\mathrm{UC}\le\mathrm{D}$.
\(\mathrm{SP}(f)\) Subcube partition complexity \(\widetilde\Theta(n^{2/3})\) Squeeze: $\mathrm{C}\le\mathrm{SP}\le\mathrm{D}$. So the two-sided partition number is maximal here, which is why the $\mathrm{R}$-vs-$\mathrm{SP}$ witness has to be the AND-composed variant.
\(\mathrm{s}(f)\) Sensitivity \(\widetilde\Theta(n^{1/3})\) putative Lower: at a $1$-input with a unique witness column, all $k$ bits of that column are sensitive. Upper: $\mathrm{s}_1\le\mathrm{C}_1=\widetilde O(n^{1/3})$; at a $0$-input a single flip must create a witness column, and per column only the unique missing $1$, the unique non-zero target, or the $O(\log k)$ bits of the list entry addressing it can do that, so $\mathrm{s}_0=O(k\log k)$.
\(\mathrm{bs}(f)\) Block sensitivity \(\widetilde\Theta(n^{1/3})\) putative Lower $\mathrm{bs}\ge\mathrm{s}$. Upper: $\mathrm{bs}_1\le\mathrm{C}_1$, and disjoint sensitive blocks at a $0$-input inject into the $k$ columns. Together with $\mathrm{C}=\widetilde\Theta(n^{2/3})$ this makes $\mathrm{C}=\widetilde\Theta(\mathrm{s}\cdot\mathrm{bs})$, i.e. Nisan's bound is tight on this family.
\(\mathrm{fbs}(f)\) Fractional block sensitivity \(\widetilde\Omega(n^{1/3})\) From $\mathrm{C}=O(\mathrm{fbs}^2)$ [Tal13] against $\mathrm{C}=\widetilde\Theta(n^{2/3})$.
\(\mathrm{FC}(f)\) Fractional certificate complexity \(\widetilde\Omega(n^{1/3})\) Squeeze: $\mathrm{FC}=\mathrm{fbs}$ exactly.
\(\mathrm{RC}(f)\) Randomized certificate complexity \(\widetilde\Omega(n^{1/3})\) Squeeze: $\mathrm{RC}=\Theta(\mathrm{fbs})$.
\(\mathrm{CA}(f)\) Classical adversary bound \(\widetilde\Omega(n^{1/3})\) Squeeze: $\mathrm{CA}=\Theta(\mathrm{fbs})$ for total functions. ABIKPS17
\(\mathrm{RS}(f)\) Sabotage complexity \(\widetilde\Omega(n^{1/3}),\ \widetilde O(n^{2/3})\) The sabotage inequality is $\mathrm{R}_\varepsilon\ge\overline{\mathrm{R}}_\varepsilon\ge(1-2\varepsilon)\mathrm{RS}$ [BenDavidKothari18, Thm 12], so $\mathrm{R}=\widetilde\Theta(n^{2/3})$ is only the ceiling. Notes

$\mathrm{TL}$ is \(f_{\mathrm{GPW}}\) made randomized-hard: replacing the GPW single pointer by a full list of $k-1$ pointers means that a randomized algorithm which has guessed the right column still cannot cheaply refute the other columns, which is what [GJPW18, Lem. 8] exploits. The price is a cell of $\Theta(k\log k)$ bits instead of $\Theta(\log k)$, which is why the exponents here read $2/3$ and $1/3$ in the input length rather than $1$ and $1/2$.

The $\mathrm{R}$-vs-$\mathrm{SP}$ witness is the AND-composed function $\mathrm{AND}_q\circ\mathrm{TL}^q$, a different function, so its numbers are not merged into the table above.
