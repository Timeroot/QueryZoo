Meiburg’s total noisy-query separation

Total functions with $\mathrm{R}/\mathrm{noisyR}=\Omega((\log N)^{1/4}/\log\log\log N)$.

total composed arity: $\log N_q=\Theta(q^4)$

Description

The certificate-array totalization of an AND-of-ORs of approximate-index seed problems, using short encoded certificates and a large address table [Meiburg26composition, Section 4].

Notes

The separation is polylogarithmic in input size, since $\log N_q=\Theta(q^4)$. It refutes constant-factor equality on total functions while remaining consistent with $\mathrm{R}=O(\mathrm{noisyR}\log(N_q+1))$ [PednekarPodder26STOC].
