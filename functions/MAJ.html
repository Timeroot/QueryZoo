\(\mathrm{MAJ}_n\)

MAJORITY

Hard for quantum too ($\mathrm{Q}=\Theta(n)$), but with sensitivity only $\approx n/2$.

total basic arity: $n$ bits, $n$ odd— also: \mathrm{THR}_{n/2}

Description

$\mathrm{MAJ}_n(x)=1$ iff $|x| > n/2$.

Formal definition

$\mathrm{MAJ}_n(x) = \mathbb{1}[\,\sum_i x_i \ge (n+1)/2\,]$ for odd $n$.

\(\deg_2(f)\) Mod-2 degree \((n+1)/2\) putative Recorded along the subfamily $n = 2^m - 1$. The $p=2$ case of the $\deg_p$ line below. The restriction to $n = 2^m-1$ is only for tidiness: running the same Lucas computation for every $n$ gives $\deg_2(\mathrm{MAJ}_n) = 2^{\lfloor \log_2 n\rfloor}$, so $\deg_2$ is always a power of two: it equals $n$ exactly when $n$ is one, and bottoms out at $(n+1)/2$ at $n = 2^m-1$, which is the case recorded here. Either way $\deg_2 = \Theta(n)$ while $\deg = n$ -- unlike \(\mathrm{IP}_n\), majority gets essentially no discount from characteristic $2$.
\(\deg_p(f)\) Mod-p degree \((n+1)/2 \text{ for } p = 2,\ n = 2^m - 1\) The $\mathbb{F}_2$ multilinear expansion of the threshold $\mathrm{Th}_k^n$ is $\sum_{|S| \ge k} \binom{|S|-1}{k-1}\prod_{i \in S} x_i$. By Lucas' theorem $\binom{s-1}{k-1}$ is odd iff the binary digits of $k-1$ are a submask of those of $s-1$; with $n = 2^m-1$ and $k = 2^{m-1}$ the only $s-1 \le n-1$ containing the mask $0\underbrace{1\cdots1}_{m-1}$ is $2^{m-1}-1$ itself, so the degree is exactly $2^{m-1} = (n+1)/2$. For $n = 3$ this is the familiar $\mathrm{MAJ}_3 = xy + yz + zx$.

\(\mathrm{D}^{\mathrm{prod}}(f)\) Product-distribution distributional complexity \(\Theta(n)\) putative The uniform distribution is already a product distribution and already hard: after $m$ queries the unseen weight is $\mathrm{Bin}(n-m,\tfrac12)$, whose standard deviation $\tfrac12\sqrt{n-m}$ exceeds the distance to the threshold with constant probability unless $n - m = O(1)$. Unlike \(\mathrm{Tribes}_{w,s}\) or \(\mathrm{ADDR}_k\), majority needs no correlated distribution to be hard.
\(\mathrm{N}_{p}(f)\) Noisy decision tree complexity \(\Theta(n\log n)\)· putative Upper: $O(\mathrm{R}\log \mathrm{R})$ by repeating each query $O(\log n)$ times. Lower: on inputs of weight $(n\pm1)/2$ the answer is determined by a margin of one bit, so an estimator of the weight must have error variance $o(1)$; a coordinate read $k$ times still has posterior error probability $2^{-\Theta(k)}$, contributing $\Theta(n2^{-\Theta(k)})$ to the variance of the estimated weight, which forces $k = \Omega(\log n)$ on a constant fraction of the coordinates. So noisy majority is a second natural $\Theta(n\log n)$ family alongside \(\oplus_n\) -- and the $\Omega(\mathrm{I}\log\mathrm{I})$ bound of [GLX26noisy] only gives $\Omega(\sqrt n\log n)$ here, so it is not the binding constraint. \(\mathrm{DTsize}(f)\) Decision tree size \(O\!\big(2^n/\sqrt n\big)\) putative The counting tree -- query until one side reaches $(n+1)/2$ -- has exactly $\binom{n+1}{(n+1)/2}$ leaves, since the stopping sequences of each type number $\sum_{j<m}\binom{m+j-1}{j} = \tfrac12\binom{2m}{m}$ with $m=(n+1)/2$.
