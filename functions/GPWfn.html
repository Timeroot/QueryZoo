\(f_{\mathrm{GPW}}\)

Goos-Pitassi-Watson partition-number function

The query-side function behind "deterministic communication vs partition number"; gives $\mathrm{D}=\widetilde\Omega(\deg^2)$.

total separating arity: $n$ bits

Description

A total function built to have small subcube-partition complexity but large deterministic complexity. Lifting it with a gadget yields the corresponding communication separation.

Formal definition

[GPW18, Thm 5]. The input is a $k\times k$ matrix over the alphabet $\Sigma = \{0,1\}\times([k]\times[k]\cup\{\bot\})$: each cell carries a bit and an optional pointer to another cell. The function is defined by an unambiguous decision tree of cost $2k-1$: guess a column, verify that all $k$ of its cells carry a $1$, follow the pointer stored in the first cell that has one, and check that the pointed-to cell carries a $0$. An adversary argument shows every deterministic tree needs $k^2$ cell queries. Encoding $\Sigma$ in $\lceil\log|\Sigma|\rceil = \Theta(\log k)$ bits gives a Boolean function on $n = \Theta(k^2\log k)$ bits and costs only that same logarithmic factor, hence $\mathrm{P}^{dt} \ge \widetilde\Omega(\mathrm{UP}^{dt\,2})$.

Measure values

\(\mathrm{D}(f)\) Deterministic query complexity \(\widetilde\Theta(n)\) The adversary of [GPW18, Sec. 2.1] survives $k^2 = \widetilde\Theta(n)$ cell queries; and $\mathrm{D}\le n$ trivially. So this function is maximally hard deterministically, up to logarithms. GPW18
\(\mathrm{D}^{\mathrm{na}}(f)\) Non-adaptive deterministic query complexity \(\widetilde\Theta(n)\) Squeezed between $\mathrm{D}=\widetilde\Omega(n)$ and the input length $n$.
\(\mathrm{C}^1(f)\) 1-certificate complexity \(\widetilde O(\sqrt n)\) The unambiguous decision tree above reads $2k-1 = \widetilde O(\sqrt n)$ cells, so $\mathrm{C}_1\le\mathrm{UC}_1\le\widetilde O(\sqrt n)$. GPW18
\(\deg(f)\) Exact degree \(\widetilde O(\sqrt n)\) Summing the indicator polynomials of the leaves of an unambiguous decision tree represents the function exactly, so $\deg\le\mathrm{UC}_1=\widetilde O(\sqrt n)$ [GPW18, Sec. 1.3]. Against $\mathrm{D}=\widetilde\Omega(n)$ this is the record $\mathrm{D}=\widetilde\Omega(\deg^2)$. GPW18
\(\mathrm{UC}_{\min}(f)\) Minimum unambiguous certificate complexity \(\widetilde\Theta(\sqrt n)\) Upper $\mathrm{UC}_{\min}\le\mathrm{UC}_1=\widetilde O(\sqrt n)$; lower from $\mathrm{D}\le\mathrm{UC}_{\min}^2$ [BHT17] against $\mathrm{D}=\widetilde\Omega(n)$. The quadratic $\mathrm{D}$-vs-$\mathrm{UC}_{\min}$ gap is therefore optimal up to logarithms.
\(\mathrm{C}^0(f)\) 0-certificate complexity \(\widetilde\Theta(n)\) putative Upper: $\mathrm{C}_0\le\mathrm{D}=\widetilde O(n)$. Lower: take the $0$-input in which every matrix bit is $1$ and each column carries its single pointer in its last cell. A $0$-certificate must refute all $k$ columns; refuting column $j$ means either pinning its pointer chain (all $k$ cells of the column, since "the first cell that has a pointer" is only determined once the earlier cells are fixed to $\bot$) or ruling out $0$-valued targets globally, which means fixing all $k^2$ matrix bits to $1$. Both cost $\Theta(k^2)$ bits $=\widetilde\Theta(n)$.
\(\mathrm{C}(f)\) Certificate complexity \(\widetilde\Theta(n)\) Squeeze: $\mathrm{C}\ge\mathrm{C}_0$ and $\mathrm{C}\le\mathrm{D}$. Note the asymmetry: $\mathrm{C}_1=\widetilde O(\sqrt n)$ but $\mathrm{C}_0$ is maximal.
\(\mathrm{UC}(f)\) Unambiguous certificate complexity \(\widetilde\Theta(n)\) Squeeze: $\mathrm{C}\le\mathrm{UC}\le\mathrm{D}$. It is the one-sided $\mathrm{UC}_1$ that is small here; the two-sided quantity is maximal, which is exactly why [GPW18] needs the AND-composed variant for the $\mathrm{SP}$ separation.
\(\mathrm{SP}(f)\) Subcube partition complexity \(\widetilde\Theta(n)\) Squeeze: $\mathrm{C}\le\mathrm{SP}\le\mathrm{D}$.
\(\mathrm{s}(f)\) Sensitivity \(\widetilde\Theta(\sqrt n)\) putative Lower: at a $1$-input with a unique witness column, all $k$ cells of that column are sensitive. Upper: $\mathrm{s}_1\le\mathrm{C}_1=\widetilde O(\sqrt n)$, and at a $0$-input a sensitive bit must single-handedly create a witness column, so it is either the target bit of one of the $k$ columns or one of the $O(\log k)$ pointer bits redirecting a column at an existing $0$, giving $\mathrm{s}_0=O(k\log k)$.
\(\mathrm{bs}(f)\) Block sensitivity \(\widetilde\Theta(\sqrt n)\) putative Lower $\mathrm{bs}\ge\mathrm{s}$. Upper: $\mathrm{bs}_1\le\mathrm{C}_1=\widetilde O(\sqrt n)$, and disjoint sensitive blocks at a $0$-input inject into the $k$ columns (two disjoint blocks cannot both complete the same column), so $\mathrm{bs}_0=O(k)$. Against $\mathrm{C}=\widetilde\Theta(n)$ this makes the function an extremal example for $\mathrm{C}=O(\mathrm{bs}^2)$ as well, alongside \(f_{\mathrm{GSS}}\).
\(\mathrm{fbs}(f)\) Fractional block sensitivity \(\widetilde\Omega(\sqrt n)\) From $\mathrm{C}=O(\mathrm{fbs}^2)$ [Tal13] against $\mathrm{C}=\widetilde\Theta(n)$. The block-injection argument recorded under $\mathrm{bs}$ suggests the matching $\widetilde O(\sqrt n)$, but the fractional relaxation is not covered by it.
\(\mathrm{FC}(f)\) Fractional certificate complexity \(\widetilde\Omega(\sqrt n)\) Squeeze: $\mathrm{FC}=\mathrm{fbs}$ exactly.
\(\mathrm{RC}(f)\) Randomized certificate complexity \(\widetilde\Omega(\sqrt n)\) Squeeze: $\mathrm{RC}=\Theta(\mathrm{fbs})$.
\(\mathrm{CA}(f)\) Classical adversary bound \(\widetilde\Omega(\sqrt n)\) Squeeze: $\mathrm{CA}=\Theta(\mathrm{fbs})$ for total functions. ABIKPS17
\(\mathrm{R}_{\varepsilon}(f)\) Bounded-error randomized query complexity \(\widetilde\Omega(\sqrt n)\) Squeeze: $\mathrm{R}=\Omega(\mathrm{fbs})$. The gap up to $\mathrm{D}=\widetilde\Theta(n)$ is not closed here -- closing it in the other direction is precisely what \(f_{\mathrm{GJPW}}\) was built for.
\(\mathrm{R}_{0}(f)\) Zero-error randomized query complexity \(\widetilde\Theta(n)\) Squeeze: $\mathrm{C}\le\mathrm{R}_0\le\mathrm{D}$, and both ends are $\widetilde\Theta(n)$. A zero-error algorithm's transcript is a certificate, so the maximal $\mathrm{C}_0$ recorded above already pins $\mathrm{R}_0$ at the top even though $\mathrm{R}$ may be far smaller.
\(\mathrm{Q}_{\varepsilon}(f)\) Bounded-error quantum query complexity \(\widetilde\Omega(n^{1/4})\) Squeeze: $\mathrm{bs}=O(\mathrm{Q}^2)$ [BBCMdW01] with $\mathrm{bs}=\widetilde\Theta(\sqrt n)$.
\(\mathrm{QC}(f)\) Quantum certificate complexity \(\widetilde\Omega(n^{1/4})\) Squeeze: $\mathrm{QC}=\Theta(\sqrt{\mathrm{fbs}})$.

\(\mathrm{s}^1(f)\) 1-sensitivity \(\widetilde\Theta(\sqrt n)\) putative Lower: at a $1$-input with a unique witness column all $k=\widetilde\Theta(\sqrt n)$ cells of that column are sensitive. Upper: $\mathrm{s}_1\le\mathrm{C}^1=\widetilde O(\sqrt n)$.

\(\mathrm{CG}(f)\) Certificate game complexity (private coin) \(\widetilde\Omega(n)\) Squeeze: $\mathrm{R}_0=O(\mathrm{CG})$ against $\mathrm{R}_0=\widetilde\Theta(n)$.
\(\mathrm{cbs}(S)\) Critical block sensitivity \(\widetilde\Theta(\sqrt n)\) For a Boolean function every input is critical and the solution function is forced, so $\mathrm{cbs}=\mathrm{bs}=\widetilde\Theta(\sqrt n)$ (\(\mathrm{cbs}(S)\) vs \(\mathrm{bs}(f)\)).

Notes

Two functions live here. The values above are for the [GPW18, Thm 5] function, whose gap is against the one-sided unambiguous width $\mathrm{UC}_1$ (their $\mathrm{UP}^{dt}$). That one-sided quantity does not upper bound $\mathrm{SP}$, since an unambiguous DNF partitions only the $1$-inputs.

For the two-sided quantity one needs [GPW18, Thm 4]: with $g$ the function above and $q := \mathrm{UC}_1(g)$, the composition $f := \mathrm{AND}_q\circ g$ satisfies $\mathrm{UC}(f)=\widetilde O(q^2)$ (certify the $q$ copies one-sidedly and pay $\mathrm{D}(g)$ on the single exceptional copy) while $\mathrm{D}$ multiplies to $\widetilde\Omega(q^3)$. Since $\mathrm{SP}\le\mathrm{UC}$, this gives $\mathrm{D}=\widetilde\Omega(\mathrm{SP}^{1.5})$, matching the earlier bound of [KRS15]. It is the communication versions that reach the quadratic gap against the partition number [GPW18, Thm 2].
