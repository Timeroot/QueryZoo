\(\mathrm{OR}_n\)

OR

The archetypal one-sided function: cheap 1-certificates, expensive 0-certificates.

total basic arity: $n$ bits— also: unstructured search (decision version), \vee

Description

$\mathrm{OR}_n(x) = 1$ iff some $x_i = 1$.

Formal definition

$$\mathrm{OR}_n : \{0,1\}^n \to \{0,1\},\qquad \mathrm{OR}_n(x) \;=\; \bigvee_{i=1}^n x_i \;=\; 1 - \prod_{i=1}^n (1-x_i).$$

\(\mathrm{UC}_{\min}(f)\) Minimum unambiguous certificate complexity \(n\) putative Corrected. $\mathrm{UC}_{\min} = \min\{\mathrm{UC}^0,\mathrm{UC}^1\}$ is the one-sided version, not a minimum over inputs. $\mathrm{UC}^0 = n$ because $0^n$ is the only $0$-input and its certificate must fix every bit. $\mathrm{UC}^1 = n$ too: an unambiguous $1$-cover partitions the $2^n-1$ ones-inputs into subcubes of sizes $2^{n-c_i}$, and an odd total forces some $c_i = n$. \(\mathrm{SP}(f)\) Subcube partition complexity \(n\) The subcube containing $0^n$ must fix all $n$ coordinates, since any free coordinate could be set to $1$; the "first $1$" tree achieves codimension $n$.
\(\mathrm{rank}(f)\) Decision tree rank \(1\) The "first $1$" tree is a caterpillar -- every internal node has a leaf child -- and rank $0$ would mean $f$ is constant.
\(\mathrm{DTsize}(f)\) Decision tree size \(n+1\) The caterpillar has $n+1$ leaves. Conversely the unique $0$-input sits at depth $n$ in any tree, and each of the $n$ branches leaving that path reaches a different leaf.

\(\mathrm{R}^{\mathrm{na}}(f)\) Non-adaptive randomized query complexity \(\Theta(n)\) A fixed distribution over query sets of size $m$ leaves some coordinate unqueried with probability $\ge 1-m/n$, and $0^n$ versus $e_i$ is then undecidable; so $m=\Omega(n)$.
\(\mathrm{noisyR}^{\mathrm{na}}(f)\) Non-adaptive noisy randomized query complexity \(\Theta(n)\) By Theorem 8, $\mathrm{noisyR}^{\mathrm{na}} = \Theta(\mathrm{R}^{\mathrm{na}})$ for every partial Boolean function. \(\mathrm{Q}_{0}(f)\) Zero-error (Las Vegas) quantum query complexity \(\Theta(n)\) Zero error costs the full $n$: the $\Theta(\sqrt n)$ of Grover is bought entirely with bounded error [BCWZ99]. \(\mathrm{Var}(f)\) Variance \(2^{2-n}(1-2^{-n})\) Exactly $4p(1-p)$ with $p = 2^{-n}$. Exponentially unbalanced, which is why every raw Fourier quantity on this page is tiny while $\mathrm{D} = n$: they are all measuring the bias, not the difficulty.
\(\mathrm{osss}(f)\) OSSS number \(2(1-2^{-n})\) putative Exactly $4p(1-p)/(2p) = 2(1-p)$, since $\mathrm{MaxInf} = 2p$. \(\mathrm{nsr}(f)\) Noise robustness \(\Theta(n)\) putative $\mathrm{NS}_\delta = 2^{1-n}(1-(1-\delta)^n)$ crosses $\mathrm{Var}/4 = 2^{-n}(1-2^{-n})$ at $(1-\delta)^n = \tfrac12(1+2^{-n})$, i.e. $\delta^{*} = (\ln 2)/n\,(1+o(1))$. Tight against $\mathrm{nsr} \le 4\mathrm{s} = 4n$: an OR tolerates as much noise as anything on $n$ relevant variables can.
\(\mathrm{NS}_{\delta}(f)\) Noise sensitivity \(2^{1-n}\big(1-(1-\delta)^n\big)\) Exact, for every $\delta$: $\vee_n(x) \ne \vee_n(y)$ holds precisely when exactly one of $x, y$ is $0^n$, and $\Pr[x = 0^n,\ y \ne 0^n] = 2^{-n}(1-(1-\delta)^n)$. So $\vee_n$ is exponentially noise-stable -- the extreme opposite of \(\oplus_n\).
\(\mathrm{Stab}_{\rho}(f)\) Noise stability \(1 - 2^{2-n}\big(1-(\tfrac{1+\rho}{2})^n\big)\) From $\mathrm{Stab}_\rho = 1 - 2\,\mathrm{NS}_{(1-\rho)/2}$ and the entry above. Tends to $1$ for every fixed $\rho$.

\(\mathrm{rdeg}_{\varepsilon}(f)\) Approximate rational degree \(1\) The single rational function $r(x) = \dfrac{n\sum_i x_i}{1 + n\sum_i x_i}$ has numerator and denominator of degree $1$, is $0$ at $0^n$, and is $\ge \tfrac{n}{n+1} \ge \tfrac23$ at every $1$-input. So one degree of freedom suffices where $\widetilde{\deg} = \Theta(\sqrt n)$ is needed for polynomials -- the cleanest illustration that rational approximation is a strictly different resource. \(\mathrm{PostQ}_{\varepsilon}(f)\) Post-selected quantum query complexity \(\Theta(1)\) $\mathrm{PostQ}_\varepsilon = \Theta(\mathrm{rdeg}_\varepsilon)$, and $\mathrm{rdeg}_\varepsilon(\mathrm{OR}) = 1$. Postselection makes unstructured search free: prepare a uniform superposition, query once, and postselect on the answer bit being $1$. MahadevdeWolf15 Aaronson05postbqp
\(\mathrm{Q}^{\mathrm{rob}}(f)\) Robust quantum query complexity \(\Theta(\sqrt n)\) Robust Grover: search over bounded-error inputs costs $O(\sqrt n)$ with no log factor, by amplitude amplification around a subroutine whose error is never amplified. Classically, noisy OR costs $\Theta(n)$ either way, so the quantum speedup survives noise intact. HoyerMoscadeWolf03 BNRdW05
\(\deg_p(f)\) Mod-p degree \(n\) For every prime $p$. Over $\mathbb{F}_p$ the multilinear representation is still $1 - \prod_i(1 - x_i)$, which contains $x_1\cdots x_n$ with coefficient $(-1)^{n+1} \ne 0$. Unlike \(\oplus_n\), OR gets no help from small characteristic -- which is why the value can be recorded as a bare $n$ with no choice of $p$ to make.
\(\mathrm{D}^{\mathrm{prod}}(f)\) Product-distribution distributional complexity \(\Theta(n)\) Take the product distribution with each bit $1$ independently with probability $1/n$. After seeing $m$ zeros the conditional probability that a $1$ remains is $1 - (1-1/n)^{n-m}$, which is $\ge 1 - e^{-1/2} > 0.39$ for $m \le n/2$; so no depth-$n/2$ tree has error $\le 1/3$. Product distributions are already as hard as OR gets, which is not true for every function.
\(\overline{\mathrm{prt}}_{\varepsilon}(f)\) Relaxed partition bound \(\Theta(n)\)· Sandwiched: $\mathrm{s}(f) \le \overline{\mathrm{prt}}_{\varepsilon}(f) \le \mathrm{D}(f)$, with both ends $n$ here. The lower end is the zoo's own observation that the [JainKlauck10] techniques survive the relaxation of the completeness constraint (see the $\mathrm{RC}\to\overline{\mathrm{prt}}$ record); the upper end is unconditional.
\(\mathrm{D}^{\mu}_{\varepsilon}(f)\) Distributional query complexity \(\Theta(n)\) By Yao's minimax principle $\max_\mu \mathrm{D}^{\mu}_{1/3}(f) = \mathrm{R}_{1/3}(f) = \Theta(n)$. A concrete maximiser: half the mass on $0^n$, the other half spread uniformly over the $n$ weight-one inputs. A depth-$d$ tree that has seen only zeros is consistent with $0^n$ and with the $n-d$ unqueried $e_i$, so whichever answer it commits to it errs on mass at least $\min\{1/2,\ (n-d)/(2n)\}$, forcing $d \ge n/3$. See \(\mathrm{D}^{\mathrm{prod}}(f)\) for the product-distribution version. Yao77
\(\mathrm{I}^{1}(f)\) Total L1 influence \(n\,2^{1-n}\) Boolean-valued, so the $L_1$ and $L_2$ total influences coincide: this is the $\mathrm{I}(f)$ recorded above.
\(\mathrm{cbs}(S)\) Critical block sensitivity \(n\) Degenerate for Boolean functions: every input is critical and the only solution function is $f$ itself, so $\mathrm{cbs}(f) = \mathrm{bs}(f)$, attained at $0^n$. The measure only says something new for search problems where some input has several valid answers. GoosPitassi14
\(\mathrm{psD}(S)\) Pseudo-deterministic query complexity \(\Theta(n)\) Degenerate for Boolean functions: there is a single correct output, so the canonical answer is forced and $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ $= \Theta(n)$. Contrast the relation \(\mathrm{ApproxHW}\), where $\mathrm{R} = O(1)$ but $\mathrm{psD} = \Omega(n)$ [CDM23]. CDM23
\(\mathrm{cjdeg}_{\varepsilon}(f)\) Conical junta degree \(\Theta(n)\)· putative Upper: $\mathrm{cjdeg}_{\varepsilon}(f) \le \mathrm{D}(f) = n$, the $1$-leaves of the caterpillar being disjoint conjunctions. Lower: let $h = \sum_C \alpha_C C$ be a width-$d$ conical junta with $|h - \vee_n| \le 1/3$ pointwise. A conjunction with $C(e_i) = 1$ either has all its literals negative -- and then $C(0^n) = 1$ as well -- or has exactly one positive literal, necessarily $x_i$. Conjunctions of the first kind contribute at most $h(0^n) \le 1/3$ to each of the $n$ points $e_i$, so writing $A$ for the total weight of the conjunctions with exactly one positive literal, $2n/3 \le \sum_i h(e_i) \le n/3 + A$, i.e. $A \ge n/3$. Now evaluate under the product measure that sets each bit to $1$ with probability $1/d$: each such $C$ has expectation at least $\tfrac1d(1-\tfrac1d)^{d-1} \ge \tfrac{1}{ed}$, while $\mathbb{E}[h] \le 4/3$, so $A \le 4ed/3$ and $d \ge n/(4e)$. Non-negativity therefore costs a quadratic blow-up over $\widetilde{\deg} = \Theta(\sqrt n)$.
