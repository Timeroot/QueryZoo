\(f_{\mathrm{Mei}}\)

Meiburg's tournament-subcube function

Refutes $\mathrm{bs} = O(\lambda^2)$: a total function with $\mathrm{bs} \ge \lambda^{2.127}$.

total composed arity: $N = 2{,}017{,}584^{\,d}$ bits ($d = 1$ is the base case)

Definition not yet transcribed. This page gives a pointer and an informal description only; the exact mathematical definition still needs to be written into data/functions/02-composed.yaml under formal:. Follow the references below.

Description

The indicator of a union of $k$ subcubes of the Boolean cube, indexed by the vertices of a doubly regular tournament; the remaining free choices in the construction are fixed by the Lovász Local Lemma. Composing the base function with itself gives an infinite family with $\lambda \to \infty$ and $\mathrm{bs} = \Omega(\lambda^{2.127})$.

\(\mathrm{bs}(f)\) Block sensitivity \(14011^{\,d}\) The base case ($d=1$) is $\mathrm{bs} \ge 14011$, established -- and formally verified in Lean -- in [Meiburg26]. Block sensitivity is supermultiplicative under block composition (plant a $\mathrm{bs}$-maximising inner input in each copy and take unions of inner blocks across each outer block), so the $d$-fold composition has $\mathrm{bs} \ge 14011^{\,d}$. Exact, not merely a lower bound: $\mathrm{bs} \le \mathrm{C} = \mathrm{C}^0 = 14011^{\,d}$ by \(\mathrm{C}^0(f)\). Meiburg26

Against the $\mathrm{bs}$ entry this gives $\mathrm{bs} \ge \lambda^{\log 14011/\log 89.0162} = \lambda^{2.127}$ for every $d$. Meiburg26 ABKRT21

\(\mathrm{C}^0(f)\) 0-certificate complexity \(14011^{\,d}\) putative Exact, and the load-bearing cell for the whole entry. The base function is the indicator of a union of $k = 14011$ subcubes, so a $0$-input is certified by naming, for each subcube, one coordinate on which it is violated: $\mathrm{C}^0 \le 14011$ for $d=1$. Since $\mathrm{C}^1 \le 7149$ (the codimension of a single subcube), $\mathrm{C} = 14011$ at $d=1$, and certificate complexity is submultiplicative under composition ($\mathrm{C}^0(F\circ g^m) \le \mathrm{C}^0(F)\,\mathrm{C}(g)$: certify the outer coordinates, then each of the corresponding inner copies), giving $\mathrm{C}^0 \le 14011^{\,d}$. The matching lower bound is $\mathrm{C}^0 \ge \mathrm{bs}^0 \ge 14011^{\,d}$ (see \(\mathrm{bs}^0(f)\)). Consequently $\mathrm{bs} = \mathrm{fbs} = \mathrm{FC} = \mathrm{EC} = \mathrm{C} = 14011^{\,d}$ exactly, all of them being squeezed between $\mathrm{bs}^0$ and $\mathrm{C}$. Meiburg26
\(\mathrm{bs}^0(f)\) 0-block sensitivity \(14011^{\,d}\) putative Lower bound: [Meiburg26, Lemma 3.1] exhibits $14011$ disjoint sensitive blocks at the all-zeros input, which is a $0$-input, so $\mathrm{bs}^0 \ge 14011$ at $d=1$. Because the witnessing input is a $0$-input in every copy, the usual planting argument keeps the $0$-side: place the all-zeros input in every inner copy and take unions of inner blocks across each outer block, so $\mathrm{bs}^0(f^{\circ d}) \ge 14011^{\,d}$. Upper bound: $\mathrm{bs}^0 \le \mathrm{C}^0 \le 14011^{\,d}$ by \(\mathrm{C}^0(f)\). The two meet, so this is exact. Meiburg26
\(\mathrm{cbs}(S)\) Critical block sensitivity \(14011^{\,d}\) putative $\mathrm{cbs} = \mathrm{bs}$ for Boolean-valued problems [GoosPitassi14]. Here $\mathrm{bs}$ is in fact pinned exactly rather than merely bounded below: $14011^{\,d} \le \mathrm{bs}^0 \le \mathrm{bs} \le \mathrm{C} \le 14011^{\,d}$, using \(\mathrm{bs}^0(f)\) and \(\mathrm{C}^0(f)\). GoosPitassi14 Meiburg26
\(\mathrm{C}^1(f)\) 1-certificate complexity \(\le 7149\cdot 14011^{\,d-1}\) putative A $1$-input of the base function lies in one of the subcubes, whose codimension is $7149$, so $\mathrm{C}^1 \le 7149$ at $d = 1$. Composing, $\mathrm{C}^1(F\circ g^m) \le \mathrm{C}^1(F)\,\mathrm{C}(g)$ -- the outer $1$-certificate fixes both $0$s and $1$s, so the inner cost is the two-sided $\mathrm{C}(g) = 14011^{\,d-1}$. No lower bound is available: nothing in the construction forces a $1$-certificate to be large. Meiburg26
\(\mathrm{C}_{\min}(f)\) Minimum certificate complexity \(\le 7149\cdot 14011^{\,d-1}\) putative $\mathrm{C}_{\min} = \min\{\mathrm{C}^0,\mathrm{C}^1\} = \mathrm{C}^1$ here, since the \(\mathrm{C}^1(f)\) bound $7149\cdot 14011^{\,d-1} \approx 0.51\cdot 14011^{\,d}$ is strictly below the exact $\mathrm{C}^0 = 14011^{\,d}$. Notes

Numerical (non-rigorous) evidence in the same paper suggests a 1255-variable relative attains exponent $\approx 2.20$, and a 30-variable instance already beats exponent $2$ with an exactly computable $\lambda$. The rigorous exponent $2.12697356\ldots$ (approximately $2.12$, usually quoted as $2.127$) is weaker than the current $2.1308255793978239\ldots$ lower endpoint supplied by Prove2Me’s refined tournament sensitivity family [Prove2MeSensitivity26]. The numerical $2.20$ value is not an established lower bound.
