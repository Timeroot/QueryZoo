Meiburg’s maximal composition-rate separation

Description

The encoded pointer block $g_q$ is the succinct total pointer function in [Meiburg26composition, Section 3], with an exact one-sided detector. Write $m_q=q^3\log q$; $q$ is odd for the majority families. Let $A_q=\mathrm{AND}_{q^2}\circ\mathrm{MAJ}_q$, on $q^3$ bits. The rotated composition is $H_q=g_q\circ A_q$.
