Description

The accepted public theorem SensitivityPrimitiveCampaign.reach_source_q5_3738277295413674_strict refines the nested tournament construction. It uses a single binary tournament labelling with ordinary defect cutoffs $(24,31,38,44,50,55)$ and source cutoff $22$, followed by an exact recursive Boolean profile. The theorem states, without construction hypotheses, that for every $\varepsilon>0$ and $S\ge2$ there is a finite total Boolean function with $\mathrm{s}\ge S$ and $\mathrm{bs}\ge\mathrm{s}^{\alpha-\varepsilon}$. The exact logarithmic quotient, rather than its rounded decimal, is the endpoint.
