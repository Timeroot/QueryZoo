\(\mathrm{AND}_n \circ \overline{\mathrm{EH}}_n\)

AND composed with NOT-EXACT-HALF

The witness for the whole rdeg column: $\mathrm{rdeg}=\Theta(n)$ while $\mathrm{s},\deg,\mathrm{D}=\Theta(n^2)$.

total composed arity: $N=n^2$ bits— also: \wedge\circ\overline{\mathrm{EH}}

Description

AND of $n$ copies of $\overline{\mathrm{EH}}_n$ (the negation of exact-half), on $N = n^2$ bits.

Formal definition

$$f(x^1,\dots,x^n) = \bigwedge_{j=1}^{n} \overline{\mathrm{EH}}_n(x^j) = \bigwedge_{j=1}^{n} \mathbb{1}\Big[\textstyle\sum_i x^j_i \ne \tfrac n2\Big].$$

\(\mathrm{s}^0(f)\) 0-sensitivity \(n = \sqrt N\) putative A $0$-input is sensitive only when exactly one block is at weight $n/2$ and the rest are $1$; then every bit of that block is pivotal and nothing else is. So $\mathrm{s}^0 = \mathrm{s}^0(\overline{\mathrm{EH}}_n) = n$ against $\mathrm{s}^1 = \Theta(n^2)$: all of the sensitivity of \(\mathrm{AND}_n \circ \overline{\mathrm{EH}}_n\) lives on the $1$-side.
\(\mathrm{s}^1(f)\) 1-sensitivity \(n^2/2 + n\) putative At a $1$-input every block has weight $\ne n/2$, and a bit is pivotal exactly when its block sits at weight $n/2\pm1$ and the bit moves it to $n/2$; a block at weight $n/2\pm1$ has $n/2+1$ such bits. Taking all $n$ blocks there gives $\mathrm{s}^1 = n(n/2+1)$, which is the recorded $\mathrm{s} = \Theta(n^2)$. Brute force confirms $\mathrm{s}^1(\overline{\mathrm{EH}}_n) = n/2+1$ for $n \le 10$.
\(\mathrm{bs}^0(f)\) 0-block sensitivity \(n = \sqrt N\) putative Every sensitive block of a $0$-input must repair every zero block, so it meets each of them and at most $n$ of them are disjoint; the $n$ singletons of a single zero block achieve it.
\(\mathrm{bs}^1(f)\) 1-block sensitivity \(n^2/2 + n\) putative Equal to $\mathrm{s}^1$: a sensitive block must push some block from weight $n/2+t$ to $n/2$, hence contains at least $t$ of that block's ones, so a block at distance $t$ supports at most $(n/2+t)/t$ disjoint sensitive blocks -- maximised at $t=1$, giving $n/2+1$ per block and $n(n/2+1)$ in all.
\(\mathrm{C}^0(f)\) 0-certificate complexity \(n = \sqrt N\) putative To certify $f = 0$ it suffices to pin one block at weight exactly $n/2$, which costs all $n$ of its bits and no fewer.
\(\mathrm{C}^1(f)\) 1-certificate complexity \(n^2/2 + n\) putative To certify $f = 1$ every block must be certified $\ne n/2$, and the cheapest witness for one block exhibits $n/2+1$ equal bits. So $\mathrm{C}^1 = n(n/2+1) = \Theta(N)$, matching the recorded $\mathrm{C}$.
\(\mathrm{C}_{\min}(f)\) Minimum certificate complexity \(n = \sqrt N\) putative The $0$-inputs are far cheaper to certify than the $1$-inputs: $\mathrm{C}_{\min} = \mathrm{C}^0 = n = \sqrt N$ against $\mathrm{C} = \Theta(N)$.
\(\mathrm{D}^{\mathrm{na}}(f)\) Non-adaptive deterministic query complexity \(N = n^2\) Every variable is relevant, and a non-adaptive algorithm must read every relevant variable.
\(\mathrm{R}^{\mathrm{na}}(f)\) Non-adaptive randomized query complexity \(\Theta(N)\) Sandwiched: $\mathrm{fbs}(f) \le \mathrm{R}^{\mathrm{na}}(f) \le \mathrm{D}^{\mathrm{na}}(f)$, with $\mathrm{fbs} = \Theta(n^2)$ and $\mathrm{D}^{\mathrm{na}} = n^2$ here.
\(\mathrm{Q}_{0}(f)\) Zero-error (Las Vegas) quantum query complexity \(\Omega(n^{3/2}),\ O(n^2)\) Between $\mathrm{Q} = \Theta(n^{3/2})$ and $\mathrm{D} = \Theta(n^2)$. The $\deg/2 = \Theta(n^2)$ floor is a $\mathrm{Q}_{\mathrm{E}}$ bound; the $\mathrm{Q}_0$ floor is $\mathrm{rdeg}/2 = \Theta(n)$, weaker than $\mathrm{Q}$ here. So whether forbidding error costs the last $\sqrt n$ is open as far as the zoo knows.
\(\mathrm{SP}(f)\) Subcube partition complexity \(\Theta(n^2)\) A monochromatic subcube partition writes $f$ as a signless sum of subcube indicators of codimension $\le \mathrm{SP}$, so $\deg \le \mathrm{SP} \le \mathrm{UC} \le \mathrm{D}$; here $\deg$ and $\mathrm{D}$ are both $\Theta(n^2)$.

\(\widetilde{\deg}_{\varepsilon}(f)\) Approximate degree \(\tilde\Theta(n^{3/2})\) The gadget has $\widetilde{\deg}(\overline{\mathrm{EH}}_n) = \Theta(n)$ by Paturi's symmetric-function formula $\Theta(\sqrt{n(n-\Gamma)})$ with $\Gamma = 1$ [Paturi92]. Upper: robustification gives $\widetilde{\deg}(f\circ g) = O(\widetilde{\deg}(f)\widetilde{\deg}(g)) = O(\sqrt n\cdot n)$ [Sherstov12robust]. \(\deg_2(f)\) Mod-2 degree \(\Theta(n^2) = \Theta(N)\) putative Over $\mathbb{F}_2$ the composition is the product $\prod_j \overline{\mathrm{EH}}_n(x^j)$ of polynomials on disjoint blocks, so $\deg_2$ adds: $\deg_2(f) = n\deg_2(\overline{\mathrm{EH}}_n)$. For the gadget the coefficient of a degree-$k$ monomial is $\binom{k}{n/2} \bmod 2$, so $\deg_2(\overline{\mathrm{EH}}_n)$ is the largest $k \le n$ whose binary expansion contains that of $n/2$ (Lucas); this is between $n/2$ and $n-1$, since $\binom{n}{n/2}$ is always even. Brute force gives $3,3,7,7$ at $n = 4,6,8,10$.
\(\mathrm{rank}(f)\) Decision tree rank \(\Theta(n^2) = \Theta(N)\) putative Upper $\mathrm{rank} \le \mathrm{D} = \Theta(n^2)$. Lower: in the Prover--Delayer game the Delayer defers on the first $n/2$ queries inside each block, scoring a point each time -- no $n/2$ bits of a block can decide $\overline{\mathrm{EH}}_n$, whose $\mathrm{C}_{\min}$ is $n/2+1$ -- and then answers the rest of that block so that it evaluates to $1$. The top $\mathrm{AND}_n$ is then undetermined until all $n$ blocks have been visited, so the Delayer scores $n\cdot n/2 = N/2$. Note this is much stronger than the generic $\mathrm{C}_{\min} \le \mathrm{rank}$, which only gives $\sqrt N$.
\(\mathrm{DTsize}(f)\) Decision tree size \(2^{\Theta(N)}\) Between $2^{\mathrm{rank}}$ and $2^{\mathrm{D}}$, both $2^{\Theta(n^2)}$ by the \(\mathrm{rank}(f)\) entry.
\(\mathrm{UC}_{\min}(f)\) Minimum unambiguous certificate complexity \(\Theta(n^2)\) putative An unambiguous $b$-certificate family of width $w$ writes $f$ (or $1-f$) as a sum of indicators of disjoint subcubes of codimension $\le w$, with no cancellation, so $\deg \le \mathrm{UC}^0$ and $\deg \le \mathrm{UC}^1$, i.e. $\deg \le \mathrm{UC}_{\min} \le \mathrm{UC}$. \(\dim_{\mathbb{F}_2}(f)\) Fourier dimension \(n^2-n = N-\sqrt N\) putative The gadget's Fourier support is exactly the even-size sets (see \(\mathrm{spar}(f)\)), which span the even-weight subspace of $\mathbb{F}_2^{n}$, of dimension $n-1$. So $\mathrm{D}^{\oplus} \le N - \sqrt N$: parity queries save something here, but only a $\sqrt N$ additive term.
\(\mathrm{I}^{1}(f)\) Total L1 influence \(2^{-\Theta(\sqrt n)} = 2^{-\Theta(N^{1/4})}\) putative For Boolean-valued $f$ the $L_1$ and $L_2$ notions of total influence coincide, $\mathrm{I}^1(f) = \mathrm{I}(f)$; see \(\mathrm{I}(f)\).
\(\mathrm{MaxInf}(f)\) Maximum influence \(2^{-\Theta(\sqrt n)} = 2^{-\Theta(N^{1/4})}\) putative The function is transitive (permute blocks, permute inside a block, since $\overline{\mathrm{EH}}_n$ is symmetric), so every coordinate has influence exactly $\mathrm{I}(f)/N = 2c(1-c)^{n-1}$ with $c = \binom{n}{n/2}2^{-n}$; dividing by the polynomial factor $N$ does not touch the $e^{-\Theta(\sqrt n)}$ of the \(\mathrm{I}(f)\) entry.
\(\mathrm{Var}(f)\) Variance \(2^{-\Theta(\sqrt n)} = 2^{-\Theta(N^{1/4})}\) From $\mathrm{Var} = 2\,\mathrm{NS}_{1/2}$ and the \(\mathrm{NS}_{\delta}(f)\) entry. The ratio to $\mathrm{MaxInf}$ is not pinned at this precision, so \(\mathrm{osss}(f)\) and \(\mathrm{nsr}(f)\) are not recorded for this function.
\(\mathrm{I}(f)\) Total influence (L2 influence) \(2^{-\Theta(\sqrt n)} = 2^{-\Theta(N^{1/4})}\) putative Exactly $\mathrm{I}(f) = 2n^2c\,(1-c)^{n-1}$ with $c = \binom{n}{n/2}2^{-n} = \Theta(n^{-1/2}) = \Pr[\overline{\mathrm{EH}}_n = 0]$: a bit of block $j$ is pivotal iff the other $n-1$ bits of its block are balanced to within one, which has probability $2c$, and every other block must be $1$. Since $cn = \Theta(\sqrt n)$, the factor $(1-c)^{n-1} = e^{-\Theta(\sqrt n)}$ swamps the polynomial $2n^2c = \Theta(n^{3/2})$. (Verified against the full Fourier expansion at $n = 4$: $\mathrm{I} = 2.9296875$.)
\(\hat{L}_1(f)\) Spectral norm \(2^{\Theta(N)}\) putative The blocks are disjoint, so $\widehat{L}_1(f) = |1 - 2q^n| + 2\big[\widehat{L}_1^{01}(\overline{\mathrm{EH}}_n)^n - q^n\big]$ with $q = 1-c$. The gadget's $0/1$ spectral norm is $2^{n/2}$ up to polynomial factors: Cauchy--Schwarz against $\sum_S \hat g(S)^2 = c$ gives $\widehat{L}_1^{01} \le \sqrt{\binom{n}{n/2}} \le 2^{n/2}$, and level $n/2$ alone contributes $\binom{n}{n/2}2^{-n}\binom{n/2}{n/4} = \Theta(2^{n/2}/n)$ when $n/2$ is even, because the Krawtchouk value there is $\pm\binom{n/2}{n/4}$. Hence $\widehat{L}_1(f) = 2^{(1/2-o(1))N}$. Exact value $19.1474\ldots$ at $n = 4$.
\(\mathrm{spar}(f)\) Fourier sparsity \(2^{N-\sqrt N}\) putative Sparsity is multiplicative over disjoint blocks, and the gadget has exactly $2^{n-1}$ nonzero coefficients: $\hat g(S)$ is $2^{-n}$ times a Krawtchouk value $K_{n/2}(|S|)$, which vanishes for every odd $|S|$ (complementation fixes the middle slice) and is nonzero for every even $|S|$ (checked for $n \le 18$). So $\mathrm{spar}(f) = (2^{n-1})^n = 2^{N-\sqrt N}$, near-maximal.
