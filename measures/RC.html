\(\mathrm{RC}(f)\)

Randomized certificate complexity

Cost of a randomized verifier that must detect, with constant probability, that the input has been changed to flip f.

Definition

$\mathrm{RC}_x(f)$ is the minimum $T$ such that there is a randomized algorithm making $T$ queries which accepts $x$ with probability $\ge 1-\varepsilon$, and rejects with probability $\ge 1/2$ any $y$ with $f(y)\ne f(x)$. $\mathrm{RC}(f) = \max_x \mathrm{RC}_x(f)$. Aaronson showed $\mathrm{RC} = \Theta(\mathrm{fbs})$.

Basic facts

  • $\mathrm{RC}(f) = \Theta(\mathrm{QC}(f)^2)$ where $\mathrm{QC}$ is quantum certificate complexity.
  • $\mathrm{RC}(f) = O(\widetilde{\deg}(f)^2)$ [Kulkarni-Tal].
  • $\mathrm{RC}(f) \le \mathrm{C}(f)$ and $\mathrm{RC}(f) \ge \mathrm{bs}(f)$.

Equivalent / near-equivalent measures

  • \(\mathrm{fbs}(f)\) $\mathrm{RC}(f) = \Theta(\mathrm{fbs}(f))$ Aaronson08 KulkarniTal16

Simon's problem partial \(\Theta(1)\) putative $\mathrm{RC} = \Theta(\mathrm{fbs}) = \Theta(1)$: to reject one fixed input of the other kind it is enough to query a random point of a block on which the two differ, which succeeds with constant probability. Deutsch-Jozsa partial \(\Theta(1)\) Sandwiched: $\mathrm{RC} \le \mathrm{R} = O(1)$, and every measure here is at least $1$.
Bernstein-Vazirani partial \(\Theta(1)\) putative One uniformly random query already distinguishes the codeword $x$ from any fixed other codeword with probability $1/2$, which is all $\mathrm{RC}$ asks; and $\mathrm{RC} = \Theta(\mathrm{fbs}) = \Theta(1)$. The contrast with $\mathrm{R} = \Theta(n)$ is the point: rejecting one alternative at a time is easy, rejecting all $2^n-1$ of them at once is not.
