\(\mathrm{D}(f)\)

Deterministic query complexity

Minimum worst-case number of queries of a deterministic decision tree computing f.

also written: decision tree complexity, DT(f), D^{dt}(f)

Definition

A deterministic decision tree is a rooted binary tree; each internal node is labelled by an index $i \in [n]$, each edge by a bit, and each leaf by an output. On input $x$ the tree follows the path determined by the bits $x_i$ it reads. $\mathrm{D}(f)$ is the minimum depth of a tree that outputs $f(x)$ on every $x$ in the domain of $f$.

Equivalently, $\mathrm{D}(f)$ is the minimum $d$ such that the adversary can be forced to reveal $f$ after $d$ bits, i.e. the "decision tree depth" of $f$.

Basic facts

  • $\mathrm{D}(f) \le n$ for total $f$, with equality for e.g. $\mathrm{PARITY}_n$.
  • $\mathrm{D}$ is the largest of all the standard measures: every other measure in this zoo is $O(\mathrm{D})$ for total functions (except the size-based ones).
  • $\mathrm{D}(f\circ g) = \mathrm{D}(f)\,\mathrm{D}(g)$ exactly, for total $f,g$ (composition is perfect).

Simon's problem partial \(\Theta(2^{n/2})\) putative Both directions are about difference sets. Upper: query $A\cup B$ where $A = \{(u,0^{n/2})\}$ and $B = \{(0^{n/2},v)\}$, which is $2^{n/2+1}-1$ points whose pairwise differences $(u,0)\oplus(0,v)=(u,v)$ exhaust $\mathbb{F}_2^n$; a two-to-one $g$ with shift $s$ must therefore repeat a value inside $A\cup B$, and an injective one never does. Note this matches $\mathrm{R}$: the birthday paradox buys randomness nothing here, because covering all $2^n$ differences deterministically is just as cheap.

Unique search partial \(n\) Adversary: answer $0$ to the first $n-1$ queries; the input can still be $0^n$ or $e_i$ at the one unqueried coordinate $i$. Reading all $n$ bits obviously suffices.
Two-or-none search partial \(n-1\) putative Adversary: answer $0$. After $n-2$ queries the two unread coordinates may both be $1$ or both be $0$, and both completions are on the promise. Conversely $n-1$ queries suffice: a $1$ anywhere settles the answer immediately, and if the first $n-1$ are all $0$ then the last coordinate cannot be $1$ alone, since $|x| = 1$ is off the promise.
Marked bit partial \(n\) putative Exactly. Upper: query $y_1,\dots,y_n$, the "is this cell marked $1$" bits. Parity-labelled FIND-1 partial \(n/4+1\) putative Exactly. Upper: query $n/4+1$ odd positions; a $1$ among them says $\mathrm{supp}(x) \subseteq \mathrm{Odd}$, and all-zero rules that case out, since $n/4$ ones would then have to fit into the $n/4-1$ odd positions left over. Lower: the adversary answers $0$ throughout. After $q_{\mathrm{odd}}$ odd and $q_{\mathrm{even}}$ even queries both completions survive as long as $n/2 - q_{\mathrm{odd}} \ge n/4$ and $n/2 - q_{\mathrm{even}} \ge n/4$, so the algorithm must spend $n/4+1$ queries inside one parity class before either answer is safe.
Approximate index partial \(\Theta(\sqrt{k\log k})\) putative So this function is not a $\mathrm{D}$-vs-$\mathrm{R}$ separation, which is worth knowing given how hard its $\mathrm{R}$ lower bound works. Lower: $\mathrm{D} \ge \mathrm{R}$. Upper: read the first $q = 4\sqrt{k\log k}$ bits of $a$ and let $b$ agree with them and be $0$ elsewhere, $b'$ agree with them and be $1$ elsewhere. Then $|b-a| + |b'-a| = k-q$, so one of the two is within $(k-q)/2 = k/2 - 2\sqrt{k\log k}$ of $a$ -- inside the ball. Query $x_b$; if it is $2$, query $x_{b'}$, which cannot be. Total $4\sqrt{k\log k}+O(1)$ queries, deterministically. Randomness buys nothing here: it only replaces "read $4\sqrt{k\log k}$ bits and use antipodal guesses" with "read $8\sqrt{k\log k}$ bits and guess at random".

Lower: $\mathrm{D} \ge \mathrm{R} = n^{\Omega(\log n)}$ at $\ell = \log n$, so at that setting the two meet and $\mathrm{D} = n^{\Theta(\log n)}$. For general $\ell$ only the upper bound is on record.
Welded trees relation \(\tilde\Theta(2^{n/2})\)· Upper $O(n\,2^{n/2})$: Shalev Ben-David, reported in [AaronsonAmbainis18, fn. 5] as $O(\sqrt N\log N)$ with $N = 2^n$ ($O(\sqrt N \log^2 N)$ with Boolean queries), and written out in full as [Liu17thesis, §4.3, Alg. 5] -- breadth-first search the top $\lceil n/2\rceil$ levels, cross using short probe-trees to tell "up" from "down", then search the last $\lfloor n/2\rfloor$ levels. Lower: $\mathrm{D} \ge \mathrm{R} = \Omega(2^{n/2}/n)$. So randomness buys essentially nothing here: $\mathrm{D}$ and $\mathrm{R}$ agree to within $n^2$. AaronsonAmbainis18 Liu17thesis
Local search on the hypercube relation \(\Theta(2^n/\sqrt n)\) [LTT89] characterise $\mathrm{D}$ for every graph in terms of vertex cuts; on the cube the optimum is essentially to query the middle layer. Quoted in this form in [SanthaSzegedy09, §1]. LTT89 SanthaSzegedy09
Local search on the grid relation \(\Theta(k^{d-1})\) Not merely $\tilde\Theta$: the deterministic case was settled before the randomized one. Upper $O(k^{d-1})$ by the divide-and-conquer of Llewellyn-Tovey-Trick: query the $(d-1)$-dimensional middle slab together with the boundary of the current region, take the smallest value seen, and recurse into whichever half contains a strictly smaller neighbour of it -- the region halves each round, so the slab costs form a geometric series. Matching $\Omega(k^{d-1})$ lower bounds are due to [LlewellynTovey93] and, independently, to Althofer and Koschnick (1993). The generic $\mathrm{D} = O(\log N\,(\Delta + s))$ of [SanthaSzegedy09, Thm. 2] with separation number $s([k]^d) = \Theta(k^{d-1})$ recovers the upper bound only up to the $\log$. LTT89 LlewellynTovey93
Fourier fishing relation \(N\) Read everything. Nothing better is possible below $\Omega(N/\log N)$, and nothing better is known at all.
Ordered search partial \(\lceil \log_2(n+1) \rceil\) Exactly. Upper: binary search. Lower: a depth-$T$ tree has at most $2^T$ leaves and must separate all $n+1$ promise inputs.
Tseitin search on an expander relation \(\Theta(n)\) Squeezed between $\mathrm{R} = \Theta(n)$ and the trivial $n$. Equivalently, by [LNNW95], the minimum depth of a tree-like resolution refutation of the Tseitin formula, which is $\Omega(n)$ on an expander. Urquhart87 BenSassonWigderson01 LNNW95
Inner product mod 2 total \(n\) From $\deg = n$ below, and $\deg \le \mathrm{D}$.
Minsky-Papert one-in-a-box total \(N = m^3\) Read-once AND-OR formulas are evasive.
Sink of a tournament total \(\Theta(m) = \Theta(\sqrt N)\) Upper: the standard candidate-elimination argument. Query $m-1$ edges to knock out all but one possible sink (a vertex with an out-edge is not a sink), then spend $m-1$ more verifying the survivor, so $\mathrm{D} \le 2m-3$. Lower: $\mathrm{D} \ge \deg = m-1$.
Scorpion graphs total \(\Theta(m) = \Theta(\sqrt N)\) Upper: at most $6m$ queries. Walk a candidate body around, maintaining a set of vertices known not to be the body; each query eliminates a vertex, so $O(m)$ queries identify $b$ or reject, and $2(m-1)$ more check $s$ and $t$. Lower: $\Omega(m)$, since the answer depends on all $m$ vertices. BvEBL74 LovaszYoung02
Graph connectivity total \(\binom{m}{2} = N\) Evasive for every $m \ge 2$: an adversary can always force all $\binom m2$ queries. One of the earliest properties proved evasive, and the model case for the Aanderaa-Karp-Rosenberg conjecture. Bollobas76 KSS84

Defined for

  • Total functions yes
    The standard setting. $\mathrm{D}(f) \le n$ always.
  • Partial functions yes
    The tree must be correct on $\mathrm{Dom}(f)$ only; behaviour off-promise is unconstrained.
  • Relations yes
    For $f \subseteq \{0,1\}^n \times \mathcal{O}$ the tree must output some $o$ with $(x,o) \in f$. Well defined whenever every $x$ has at least one valid output.
