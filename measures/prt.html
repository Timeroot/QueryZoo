\(\mathrm{prt}_{\varepsilon}(f)\)

Partition bound

LP relaxation of "cover the cube by few low-codimension monochromatic subcubes"; subsumes most classical lower bound techniques.

also written: partition bound, \mathrm{prt}(f)

Definition

Introduced for query complexity (not merely imported from communication complexity) in [JainKlauck10, Def. 15]. There is a variable $w_{A,z}\ge 0$ for every partial assignment $A$ -- equivalently every subcube -- and every output $z$, and the LP is $$\min \sum_{A,z} w_{A,z}\, 2^{|A|} \quad\text{s.t.}\quad \sum_{A \ni x} w_{A,f(x)} \ge 1-\varepsilon \ \text{ and }\ \sum_{A \ni x,\, z} w_{A,z} = 1 \qquad \text{for every } x ,$$ where $|A|$ is the number of fixed variables. Read $w_{A,z}$ as "probability that a zero-communication prover announces the subcube $A$ and the answer $z$": the second constraint says exactly one subcube fires on each input, the first says the answer is right with probability $1-\varepsilon$, and $2^{|A|}$ prices a codimension-$|A|$ subcube at the number of leaves it would take to isolate it.

The LP optimum is on a number-of-leaves scale, so throughout this zoo $\mathrm{prt}_\varepsilon(f)$ denotes its logarithm, $$\mathrm{prt}_\varepsilon(f) \;:=\; \log_2\Big(\text{optimum of the LP above}\Big),$$ which is the quantity that is comparable with $\mathrm{D}$ and $\mathrm{R}$. Beware that [JainKlauck10] write $\mathrm{prt}_\varepsilon(f)$ for the optimum itself and carry the $\log$ around explicitly. The integral version of the LP is "partition the cube into monochromatic subcubes", so $\mathrm{prt}(f) \le O(\mathrm{SP}(f)) \le O(\mathrm{D}(f))$.

Parameters

\(\varepsilon\) (eps) default \(1/3\)

Error parameter.

Basic facts

  • $\mathrm{prt}_\varepsilon(f) \le 2\,\mathrm{R}_\varepsilon(f)$ -- it is a lower bound technique for randomized query complexity [JainKlauck10, Thm 3.1]. The factor $2$ is real for the price used above: a complete tree of depth $d$ has $2^d$ leaves each costing $2^d$, for an LP value of $4^d$.
  • It subsumes essentially every classical technique in this zoo [JainKlauck10, Thm 3]: $\mathrm{prt}_0(f) \ge \mathrm{C}(f)$; $\mathrm{prt}_{\varepsilon/4}(f) \ge \varepsilon\,\mathrm{bs}(f) + \log\varepsilon - 2$; $\mathrm{prt}_\varepsilon(f) \ge \mathrm{RC}_{2\varepsilon/(1-2\varepsilon)}(f) + \log \varepsilon$; $\mathrm{prt}_\varepsilon(f) \ge (1-4\varepsilon)\,\mathrm{CA}(f) + \log\varepsilon$; and $\mathrm{prt}_\varepsilon(f) \ge \widetilde{\deg}_{2\varepsilon}(f) + \log\varepsilon$ for Boolean $f$.
  • It is not too far from $\mathrm{D}$ either: $\mathrm{D}(f) = O\big(\mathrm{prt}_0(f)\cdot \mathrm{prt}_{1/3}(f)\big)$ and $\mathrm{D}(f) = O\big(\mathrm{prt}_{1/3}(f)^3\big)$ [JainKlauck10, Thm 3.7]. So for total $f$ the partition bound is polynomially related to everything else in the classical column.
  • But it is not tight: there is a total $f$ with $\mathrm{RS}(f) \ge \mathrm{prt}(f)^{2-o(1)}$, hence $\mathrm{R}(f) \ge \mathrm{prt}(f)^{2-o(1)}$ [BenDavidKothari18, Thm 30].
  • Query-to-communication lifting theorems typically show $\mathrm{prt}$-type query bounds lift to communication bounds.
