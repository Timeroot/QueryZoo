\(\mathrm{PostQ}_{\varepsilon}(f)\)

Post-selected quantum query complexity

Quantum queries when the algorithm may post-select on an exponentially unlikely event.

Definition

The algorithm may condition on a measurement outcome of arbitrarily small probability (the class $\mathsf{PostBQP}$ analogue). Mahadev-de Wolf showed this is exactly characterised by rational approximation: $$\mathrm{PostQ}_\varepsilon(f) = \Theta(\mathrm{rdeg}_\varepsilon(f)).$$

Parameters

\(\varepsilon\) (eps) default \(1/3\)

Basic facts

  • Post-selection and bounded error are incomparable resources: for partial functions there are unbounded separations between $\mathrm{rdeg}$ and $\widetilde{\deg}$ in both directions [IJKKKSWW23].

Equivalent / near-equivalent measures

  • \(\mathrm{rdeg}_{\varepsilon}(f)\) $\mathrm{PostQ}_\varepsilon(f)=\Theta(\mathrm{rdeg}_\varepsilon(f))$ -- bounded error on both sides MahadevdeWolf15 IJKKKSWW23
  • \(\mathrm{rdeg}(f)\) $\mathrm{PostQ}_{\mathrm{E}}(f) = \Theta(\mathrm{rdeg}(f))$ -- the exact-error versions of both. Not an equivalence between $\mathrm{PostQ}_{1/3}$ and $\mathrm{rdeg}_0$, which are genuinely different quantities. MahadevdeWolf15 IJKKKSWW23

Unstructured search (relation) relation \(\Theta(1)\)· putative Postselection trivialises search. Prepare $\sum_{i} \alpha_i |i\rangle + \varepsilon|\bot\rangle$ with $\alpha_i = n^{-1/2}$, query $x_i$ into a flag qubit (flag $= x_i$ on the $|i\rangle$ branches, flag $= 1$ on the $|\bot\rangle$ branch), and postselect on flag $= 1$. With $\varepsilon = 1/n$ the surviving state is a uniform superposition over $\{i : x_i = 1\}$ plus a $|\bot\rangle$ component of weight $\varepsilon^2/(\varepsilon^2 + |x|/n) \le 1/n$, so on any $x \ne 0^n$ the measurement returns a valid index, and on $x = 0^n$ only $|\bot\rangle$ survives. Welded trees relation \(O(n)\) Post-selection can only help, so $\mathrm{PostQ}\le\mathrm{Q}=\Theta(n)$. Whether it helps at all here is open; the quantum walk already runs in linear time.
Local search on the hypercube relation \(O(2^{n/3}n^{1/6})\) Post-selection can only help, so $\mathrm{PostQ}\le\mathrm{Q}=\Theta(2^{n/3}n^{1/6})$.
Local search on the grid relation \(O(k^{d/3})\ (d \ge 6)\) Post-selection can only help, so $\mathrm{PostQ}\le\mathrm{Q}=\Theta(k^{d/3})$.
Fourier fishing relation \(\Theta(1)\) $1\le\mathrm{PostQ}\le\mathrm{Q}=1$: one Fourier sample already solves the problem, and no problem with a nonconstant answer is solved with zero queries. Post-selection has nothing left to buy -- the interest of this family is entirely on the classical side.
Ordered search partial \(\Theta(1)\) $\mathrm{PostQ}_\varepsilon=\Theta(\mathrm{rdeg}_\varepsilon)=\Theta(1)$ [MahadevdeWolf15]. Post-selection collapses ordered search: $\mathrm{Q}=\Theta(\log n)$ but a post-selected algorithm needs only a constant number of queries. MahadevdeWolf15
Tseitin search on an expander relation \(O(\sqrt n)\) Post-selection can only help, so $\mathrm{PostQ}\le\mathrm{Q}=O(\sqrt n)$.
Inner product mod 2 total \(\Theta(n)\) $\mathrm{PostQ}_{\varepsilon}(f) = \Theta(\mathrm{rdeg}_{\varepsilon}(f))$ [MahadevdeWolf15], and the approximate rational degree is $\Theta(n)$ here. MahadevdeWolf15
Minsky-Papert one-in-a-box total \(\Omega(m),\ O(m^{3/2})\) $\mathrm{PostQ}_{\varepsilon}(f) = \Theta(\mathrm{rdeg}_{\varepsilon}(f))$ [MahadevdeWolf15], and the approximate rational degree sits in $[\Omega(m), O(m^{3/2})]$ here; see \(\mathrm{rdeg}_{\varepsilon}(f)\). So it is open whether post-selection beats plain quantum on the one-in-a-box function, and the whole question is the constant-vs-$\sqrt m$ gap in that window. MahadevdeWolf15
