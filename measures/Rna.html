\(\mathrm{R}^{\mathrm{na}}(f)\)

Non-adaptive randomized query complexity

Bounded-error cost when the query set is drawn from a distribution fixed in advance, independent of the answers.

also written: oblivious randomized decision tree complexity

Definition

The algorithm samples a set $S \subseteq [n]$ from a distribution of its choosing, learns $x|_S$, and outputs a guess that must be correct with probability $\ge 2/3$. $\mathrm{R}^{\mathrm{na}}_\varepsilon(f)$ is the least $\max |S|$ over the support (the worst-case version; the expected-cost version is the natural companion, as for $\bar{\mathrm{R}}$).

Non-adaptivity is the standard restriction in property testing, where "adaptive vs non-adaptive" is one of the two axes (the other being one-sided vs two-sided error).

Parameters

\(\varepsilon\) (eps) default \(1/3\)

error probability

Basic facts

  • $\mathrm{R}(f) \le \mathrm{R}^{\mathrm{na}}(f) \le \mathrm{D}^{\mathrm{na}}(f)$, and in the other direction $\mathrm{R}^{\mathrm{na}}_\varepsilon(f) \le 2^{\mathrm{R}_\varepsilon(f)}-1$: sample a tree from the optimal distribution and read every variable it could ever query.
  • Yao's minimax applies verbatim: $\mathrm{R}^{\mathrm{na}}_\varepsilon(f) = \max_\mu \mathrm{D}^{\mathrm{na},\mu}_\varepsilon(f)$, the max over input distributions of the best fixed query set of that size.
  • Adaptivity can save exponentially even with randomness: $\mathrm{R}(\mathrm{ADDR}) = \Theta(\log n)$ while $\mathrm{R}^{\mathrm{na}}(\mathrm{ADDR}) = \Theta(n)$, since a fixed distribution over $k$ data bits finds the addressed bit with probability $\le k/n$ and must otherwise guess.
  • For $\mathrm{OR}_n$ adaptivity buys nothing: $\mathrm{R}(\mathrm{OR}_n) = \Theta(n) = \mathrm{R}^{\mathrm{na}}(\mathrm{OR}_n)$.
  • Non-adaptively, noise is free to resist: $\mathrm{R}^{\mathrm{na}}(f) = \Theta(\mathrm{noisyR}^{\mathrm{na}}(f))$ for every partial Boolean $f$ [BenDavidBlais20composition, Thm. 8], although the same statement is false for relations. Contrast the adaptive case, where $\mathrm{noisyR}$ can be exponentially smaller than $\mathrm{R}$.

Welded trees relation \(\Theta(4^n)\) putative Randomness does not help the non-adaptive algorithm either, so $\mathrm{R}^{\mathrm{na}}/\mathrm{R} = \tilde\Theta(2^{3n/2})$ as well. Upper: $\mathrm{R}^{\mathrm{na}} \le \mathrm{D}^{\mathrm{na}} = \Theta(4^n)$. Lower: let the algorithm draw a random name set $S$, $|S| = t$. Since $\pi$ is a uniformly random injection with only $\pi(\mathrm{ENTRANCE})$ pinned, the exit and its two neighbours land in $S$ with probability at most $3t/(2^{2n}-1)$; conditioned on missing all three, the transcript is independent of which unqueried unused name carries the exit, and there are $2^{2n} - t - 2^{n+2}$ candidates. So the success probability is at most $3t/(2^{2n}-1) + o(1)$, and $t = \Omega(4^n)$ is needed for $2/3$.
Local search on the hypercube relation \(\Theta(2^n)\) putative Randomness buys nothing without adaptivity, and the gap against $\mathrm{R} = \Theta(2^{n/2}\sqrt n)$ is quadratic. Upper: $\mathrm{R}^{\mathrm{na}} \le \mathrm{D}^{\mathrm{na}} = 2^n$. Lower: pick $u$ uniformly and let $f$ be the Hamming distance to $u$ except at $u$ itself, where $f(u) \in \{0, 2n\}$ with a fair coin. Both completions are legal, the reading on any cell other than $u$ is identical, and the valid outputs are disjoint -- $\{u\}$ in one case, the $n$ neighbours of $u$ in the other. A fixed query set $S$ of size $t$ contains $u$ with probability $t/2^n$, so the success probability is at most $t/2^n + 1/2$ and $t \ge 2^n/6$.
Local search on the grid relation \(\Theta(k^d)\) putative Every cell, even with randomness, so $\mathrm{R}^{\mathrm{na}} = \Theta(\mathrm{D}^{\mathrm{na}}) = \Theta(N)$. Randomise the \(\mathrm{D}^{\mathrm{na}}(f)\) construction: draw $u$ uniformly from $[k]^d$, let $f$ be the $\ell_1$ distance to $u$ off $u$, and set $f(u) \in \{0, 2dk\}$ by a fair coin. The two completions have disjoint solution sets and agree everywhere but $u$, so a fixed query set of size $t$ succeeds with probability at most $t/k^d + 1/2$.
Fourier fishing relation \(\Omega(N/\log N),\ O(N)\) Sandwiched between $\mathrm{R}_{\varepsilon} = \Omega(N/\log N)$ and $\mathrm{D}^{\mathrm{na}} = N$.
Ordered search partial \(\Theta(n)\) putative Randomness does not rescue non-adaptivity. Take $k$ uniform on $\{0,\dots,n\}$; a fixed query set of size $t$ leaves the parity determined only when the gap containing $k$ is a singleton, and there are at most $t+1$ singleton gaps, so the algorithm is right with probability at most $\tfrac{t+1}{n+1} + \tfrac12\big(1-\tfrac{t+1}{n+1}\big)$. Forcing this to $\ge 2/3$ gives $t \ge \tfrac{n+1}{3}-1$. Upper: $\mathrm{R}^{\mathrm{na}} \le \mathrm{D}^{\mathrm{na}} = n$.
Tseitin search on an expander relation \(\Theta(n)\) Between $\mathrm{R} = \Theta(n)$ and $\mathrm{D}^{\mathrm{na}} = n$.
Inner product mod 2 total \(\Theta(n)\) Between $\mathrm{R} = \Theta(n)$ and $n$.
Minsky-Papert one-in-a-box total \(\Theta(m^3) = \Theta(N)\) Between $\mathrm{R} = \Theta(N)$ and $\mathrm{D}^{\mathrm{na}} = N$.
Sink of a tournament total \(\Theta(m^2) = \Theta(N)\) putative Non-adaptively you must read essentially the whole tournament, a full quadratic above $\mathrm{R} = \Theta(\sqrt N)$. Hard distribution: pick $v$ and $u \ne v$ uniformly, orient every edge into $v$ and the rest of the tournament uniformly at random, then flip the edge $uv$ with probability $1/2$. Flipping it destroys the sink and creates a new one only if $u$ is a sink of the sub-tournament, which happens with probability $2^{-(m-2)}$. The unordered pair $\{u,v\}$ is uniform over all $\binom m2$ edges, and flipping the coin is an involution that leaves $x|_S$ unchanged whenever $uv \notin S$, so any fixed $S$ errs with probability $\ge \tfrac12(1 - |S|/\binom m2) - 2^{-(m-2)}$. Hence $|S| = \Omega(N)$, and $\mathrm{R}^{\mathrm{na}} \le \mathrm{D}^{\mathrm{na}} = N$.
Scorpion graphs total \(\Theta(m^2) = \Theta(N)\) putative Non-adaptively the scorpion property is evasive up to a constant, a full quadratic above $\mathrm{R} = \Theta(\sqrt N)$. Hard distribution: draw an ordered triple $(s,t,b)$ uniformly and the foot subgraph uniformly, giving a scorpion $G$, then delete the edge $st$ with probability $\tfrac12$ (which isolates $s$, so the result is never a scorpion). Flipping that coin is a measure-preserving involution that does not change $x|_S$ whenever $st \notin S$, so given $x|_S$ the answer is an unbiased coin on that event; since $\{s,t\}$ is uniform over all $\binom m2$ pairs, a fixed $S$ succeeds with probability at most $1 - \tfrac12(1 - |S|/\binom m2)$, forcing $|S| \ge \binom m2/3$. Upper: $\mathrm{R}^{\mathrm{na}} \le \mathrm{D}^{\mathrm{na}} = N$.
