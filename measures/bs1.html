\(\mathrm{bs}^1(f)\)

1-block sensitivity

Block sensitivity maximised only over 1-inputs.

Definition

$\mathrm{bs}^1(f) = \max_{x \in f^{-1}(1)} \mathrm{bs}_x(f)$.

Basic facts

  • $\mathrm{bs}(f) = \max(\mathrm{bs}^0(f), \mathrm{bs}^1(f))$ and $\mathrm{s}^1(f) \le \mathrm{bs}^1(f)$.
  • $\mathrm{C}^1(f) \le \mathrm{s}^0(f)\,\mathrm{bs}^1(f)$ [Nisan91], the one-sided form of $\mathrm{C} \le \mathrm{s}\cdot\mathrm{bs}$.
  • $\mathrm{bs}^1(f) = \mathrm{bs}^0(\bar f)$, so every statement about one is a statement about the other with $f$ negated.

Rubinstein's function total \(n = \sqrt N\) putative Every sensitive block of a $1$-input must stop the firing block, so all of them meet its $n$ bits and at most $n$ are disjoint; the $n$ singletons work. So the quadratic gap is entirely one-sided: $\mathrm{bs}^0 = \tfrac12(\mathrm{bs}^1)^2$.
Ambainis-Sun function total \(3k+2\) putative Every sensitive block of a $1$-input must destroy the pattern that is firing, so it meets that pattern's $3k+2$ pinned bits; at most $3k+2$ such blocks are disjoint, and the singletons work. So the separation is one-sided, as in \(f_{\mathrm{Rub}}\).
AND composed with NOT-EXACT-HALF total \(n^2/2 + n\) putative Equal to $\mathrm{s}^1$: a sensitive block must push some block from weight $n/2+t$ to $n/2$, hence contains at least $t$ of that block's ones, so a block at distance $t$ supports at most $(n/2+t)/t$ disjoint sensitive blocks -- maximised at $t=1$, giving $n/2+1$ per block and $n(n/2+1)$ in all.
Pointer functions total \(\widetilde\Theta(\sqrt n)\) putative Variant $f_{2m,m}$. The $2m$ singleton blocks of the $\mathrm{s}^1$ line are pairwise disjoint and each is sensitive, so $\mathrm{bs}^1\ge\mathrm{s}^1=\widetilde\Omega(\sqrt n)$; the ceiling is $\mathrm{bs}^1\le\mathrm{bs}=\widetilde O(\sqrt n)$.
Cheat-sheet functions total \(\widetilde O(\sqrt n)\) Squeeze: $\mathrm{bs}^1\le\mathrm{bs}=\widetilde O(\sqrt n)$. Nisan's refined bound $\mathrm{C}^1\le\mathrm{s}^0\,\mathrm{bs}^1$ with $\mathrm{C}^1=\widetilde\Theta(\sqrt n)$ and $\mathrm{s}^0=\widetilde O(\sqrt n)$ gives only $\mathrm{bs}^1=\widetilde\Omega(1)$, so neither side of $\mathrm{bs}$ can be pinned from the recorded data.
Unambiguous-DNF / Alon-Saks-Seymour function total \(\widetilde O(n)\) Squeeze: $\mathrm{bs}_1\le\mathrm{C}^1\le\mathrm{UC}_1=\widetilde O(n)$. Read against the recorded $\mathrm{bs}_0=\widetilde\Omega(n^{4/3})$ this makes the block sensitivity of this family genuinely one-sided: all of it lives on the $0$-inputs, exactly like $\mathrm{C}$.
Gilmer-Saks-Srinivasan functions total \(n\) putative Squeezed between $\mathrm{s}_1=n$ and $\mathrm{C}^1=n$. So the whole $\mathrm{C}$-vs-$\mathrm{bs}$ gap of this family lives on the $0$-side, where $\mathrm{C}^0=\Theta(n^2)$ but $\mathrm{bs}_0=\Theta(n)$.
