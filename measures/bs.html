Measures › Combinatorial
\(\mathrm{bs}(f)\)

Block sensitivity

Max number of disjoint blocks of coordinates each of whose flips changes the output.

Definition

$\mathrm{bs}_x(f)$ is the maximum number of pairwise disjoint sets $B_1,\dots,B_k \subseteq [n]$ with $f(x^{\oplus B_j}) \ne f(x)$ for all $j$; $\mathrm{bs}(f) = \max_x \mathrm{bs}_x(f)$, and $\mathrm{bs}^b$ restricts to $f^{-1}(b)$. Restricting to singleton blocks recovers sensitivity. The $\ell$-bounded variant $\mathrm{bs}_\ell$ requires $|B_j| \le \ell$.

Basic facts

  • $\mathrm{bs}(f) \le \mathrm{D}(f)$ and $\mathrm{bs}(f) \le 3\,\mathrm{R}(f)$ [Nisan].
  • $\mathrm{bs}(f) \le 2\deg(f)^2$ and $\mathrm{bs}(f) \le 6\widetilde{\deg}(f)^2$ [Nisan-Szegedy].
  • $\mathrm{bs}(f) = O(\mathrm{Q}(f)^2)$.
  • $\mathrm{bs}_\ell(f) = O(\mathrm{s}(f)^\ell)$ [Kenyon-Kutin].
  • Whether $\mathrm{D}(f) = O(\mathrm{bs}(f)^2)$ is a long-standing open problem.
  • Universal quadratic bounds are false: [OpenAISensitivity26] give a fixed separation exponent $\alpha>2$. The public Prove2Me theorem improves the lower endpoint to $\alpha=\log(14055^8)/\log(3738277295413674)=2.1308255793978239\ldots$ [Prove2MeSensitivity26]. The universal quartic upper bound remains.

FORRELATION partial \(O(1)\) Two arguments, the second much sharper. Counting: flipping $m$ coordinates moves $\Phi$ by at most $2m/\sqrt n$, so every sensitive block has $\Omega(\sqrt n)$ coordinates and at most $O(\sqrt n)$ of them are disjoint. Adversary: $\mathrm{bs}(f) \le \mathrm{Adv}(f)^2$ holds for partial $f$ as well (\(\mathrm{bs}(f)\) vs \(\mathrm{Adv}(f)\) -- disjointness of the blocks is all the proof uses), and $\mathrm{Adv} \le \mathrm{Adv}^{\pm} = \Theta(\mathrm{Q}) = \Theta(1)$ here. So block sensitivity is constant against $\mathrm{D} = \Theta(n)$, and it does not even see the $\widetilde\Theta(\sqrt n)$ scale of $\mathrm{R}$.
k-FORRELATION partial \(O(k^2)\) $\mathrm{bs} \le \mathrm{Adv}^2$ for partial $f$ (\(\mathrm{bs}(f)\) vs \(\mathrm{Adv}(f)\)), and $\mathrm{Adv} \le \mathrm{Adv}^{\pm} = \Theta(k)$. Also $\mathrm{bs} \le \mathrm{fbs}$.
Simon's problem partial \(2\) putative Every sensitive block has size $\ge 2^{n-1}$: crossing between the injective and the two-to-one side requires touching each of the $2^{n-1}$ pairs $\{x, x\oplus s\}$ at least once. Two disjoint blocks of exactly that size exist -- the two transversals of the pairing -- and three do not fit in $2^n$ points. So $\mathrm{bs}^0 = \mathrm{bs}^1 = 2$.
Deutsch-Jozsa partial \(2\) putative At $0^N$ the sensitive blocks are exactly the $\binom{N}{N/2}$ half-sized sets, and two disjoint halves fit; at a balanced $x$ they are exactly $\mathrm{supp}(x)$ and its complement, again two disjoint blocks. Three disjoint blocks of size $N/2$ do not fit in $N$ coordinates, so $\mathrm{bs}^0=\mathrm{bs}^1=2$.
Bernstein-Vazirani partial \(1\) putative The sensitive blocks at the input $x$ indexed by $s$ are exactly the sets $B_d = \{i : \langle d, i\rangle = 1\}$ for $d = s \oplus s' \ne 0$. Any two of them meet -- $|B_{d} \cap B_{d'}| = 2^{n-2} > 0$ for distinct nonzero $d, d'$ -- so no two disjoint sensitive blocks exist. Hence $\mathrm{s} = 0 < \mathrm{bs} = 1$, itself a small curiosity that no total function allows.

Two-or-none search partial \(\lfloor n/2 \rfloor\) putative The maximum of $\mathrm{bs}^0 = \lfloor n/2\rfloor$ and $\mathrm{bs}^1 = 1$.
Marked bit partial \(1\) putative An answer-flipping block must clear every current mark and plant one of the other colour, so all sensitive blocks contain the encoding bit of some fixed existing mark and no two are disjoint. There is at least one, so $\mathrm{bs} = 1$.
Dense marked bit partial \(1\) putative At any $x$ every sensitive block must clear all of $x$'s marks and plant $n/2$ of the other colour, so all sensitive blocks at $x$ share the coordinates of $x$'s marks and no two are disjoint.
Gap-Majority partial \(\Theta(\min(n, 1/\delta))\) Every sensitive block at a promise input must move at least $2\delta n$ coordinates, so disjoint blocks number at most $1/(2\delta)$; and at an input of weight exactly $n/2+\delta n$ that many disjoint blocks of $2\delta n$ ones each do flip the answer.
Gap-Majority at constant gap partial \(1\) A sensitive block must move at least $2\delta n = n/2$ coordinates, and an input of weight $3n/4$ has room for exactly one such block.
Parity-labelled FIND-1 partial \(1\) putative Exactly $1$. A sensitive block at $x$ must produce a domain input of the other value, and such an input is $0$ on all of $\mathrm{supp}(x)$; so every sensitive block contains $\mathrm{supp}(x)$ and no two of them are disjoint. One block exists -- swap $\mathrm{supp}(x)$ for any $n/4$ coordinates of the other parity -- so $\mathrm{bs} = 1$ while $\mathrm{D} = n/4+1$.
Approximate index partial \(1\) putative Exactly one, so no two sensitive blocks are disjoint. After any answer-flipping change every non-$2$ cell holds $1-v$, whereas at present every one of the $|B(a,r)|$ cells of the ball holds $v$; so every sensitive block contains the whole ball, and any two of them meet. There is at least one (rewrite everything), so $\mathrm{bs} = 1$.
Collision problem partial \(2\) putative Crossing between the two sides forces a change in each of the $n/2$ pairs, so every sensitive block has $\ge n/2$ of the $n$ coordinates: at most two disjoint ones, and two transversals of the pairing achieve it. $\mathrm{bs}^0 = \mathrm{bs}^1 = 2$.
Element distinctness total \(n\) putative The $n$ singleton blocks above are disjoint, and $\mathrm{bs} \le n$.

So block sensitivity is blind to the $\Omega(n^{1/3})$ lower bound, as is everything below it. Ambainis02

Recursive Fourier sampling partial \(1\) putative The promise is rigid enough that no block of the oracle can be flipped and stay inside it. Worth recording because it is precisely why the polynomial method says nothing here. Aaronson10
Ordered search partial \(2\) putative Decision version. Flipping a block $B$ of $0^k1^{n-k}$ stays on the promise only if $B$ is the interval between the old and the new boundary, so every sensitive block contains position $k$ (if it moves the boundary down) or position $k+1$ (if it moves it up). Two disjoint sensitive blocks are therefore the most possible, and $k\pm1$ supplies them.
