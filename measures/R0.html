\(\mathrm{R}_{0}(f)\)

Zero-error randomized query complexity

Expected number of queries of a randomized algorithm that is always correct.

also written: Las Vegas query complexity, ZPP-style query complexity

Definition

The minimum over always-correct randomized algorithms of the worst-case expected number of queries. (Worst-case cost would collapse to $\mathrm{D}$, so the expected-cost convention is forced here.) Equivalently the algorithm may output "don't know" with probability $\le 1/2$ and otherwise must be right ("Las Vegas").

Basic facts

  • $\mathrm{R}(f) \le \mathrm{R}_0(f) \le \mathrm{D}(f)$.
  • $\mathrm{D}(f) = O(\mathrm{R}_0(f)^2)$ for total $f$; tight up to $\tilde\Omega$ by pointer functions [ABBLSS17].
  • $\mathrm{R}_0(f) = O\big(\mathrm{R}(f)^2\log \mathrm{R}(f)\big)$ [KulkarniTal16], improving $O(\mathrm{R}(f)^2\log n)$ [Midrijanis05].
  • $\mathrm{R}_0(\text{NAND-tree}_n) = \Theta(n^{0.7537\ldots})$ [Saks-Wigderson], matching $\mathrm{R}$ [Santha].

Dense marked bit partial \(\Theta(1)\) putative At most $4$. Pick a uniformly random cell $b$ and query $y_b$; if it is $1$, output $1$ -- correct with certainty, since by the promise no domain input carries marks of both colours. Otherwise query $z_b$; if it is $1$, output $0$. Otherwise the cell is blank: discard it and repeat with a fresh random cell. At least half the cells are marked, so each round succeeds with probability $\ge 1/2$ and costs $\le 2$ queries; the expected total is $\le 4$. The algorithm never answers without holding a mark, so it is zero-error, and \(\mathrm{R}_{0}(f)\) is the expected-cost measure, which is what makes this legal -- the worst-case count is $\Omega(n)$, since an unlucky run can sample every blank cell first.

Triangle finding total \(\Theta(m^2) = \Theta(n)\) Sandwiched: $\mathrm{R}_{\varepsilon}(f) \le \mathrm{R}_{0}(f) \le \mathrm{D}(f)$, with both ends $\Theta(m^2)$ here.
Recursive Fourier sampling partial \(n^{\Omega(\log n)} \text{ at } \ell = \log n\) From $\mathrm{R}_{\varepsilon} \le \mathrm{R}_0$ and the [BernsteinVazirani97] bound on $\mathrm{R}$; capped above by $\mathrm{D} = O(n^{\ell})$.
Welded trees relation \(\tilde\Theta(2^{n/2})\) Sandwiched: $\mathrm{R}_{\varepsilon} \le \tfrac32\mathrm{R}_0$ and $\mathrm{R}_0 \le \mathrm{D}$, and both ends are $\tilde\Theta(2^{n/2})$. The classical algorithm never gains from being allowed to err: it finds the EXIT by walking to it.
Local search on the hypercube relation \(\Theta(2^{n/2}\sqrt n)\) A candidate local minimum is verified with $\Delta = n$ further queries, so $\mathrm{R}_0 = O(\mathrm{R} + n)$, and $n \ll \mathrm{R}$ here. Same remark as on \(\mathrm{Find1}_{\ge n/2}\).
Local search on the grid relation \(\Theta(k^{d/2})\ (d \ge 4)\) A candidate local minimum is verified with $\Delta = 2d = O(1)$ further queries, so $\mathrm{R}_0 = O(\mathrm{R} + d)$; with $d$ constant this is $\Theta(k^{d/2})$. Same remark as on \(\mathrm{LS}(\{0,1\}^n)\).
Fourier fishing relation \(\Theta(N)\) putative Settled, unlike $\mathrm{R}$ itself: the $\log N$ window that is open for bounded error closes at zero error. Upper $\mathrm{R}_0 \le \mathrm{D} = N$. Lower: $\mathrm{C} = O(\mathrm{R}_0)$ (\(\mathrm{C}(f)\) vs \(\mathrm{R}_{0}(f)\)) -- fix the coins of a zero-error algorithm and the transcript it produces must force a valid answer, so it is a certificate -- and $\mathrm{C} \ge N/2$ by the row below. So $\mathrm{R}_0 \ge N/4$, and Fourier fishing separates $\mathrm{R}_0$ from $\mathrm{R}$ by at least the same $\log N$ that separates $\mathrm{R}$ from $\mathrm{D}$.
Ordered search partial \(\log_2 n \pm \Theta(1)\) Sandwiched: $\mathrm{R} \le \mathrm{R}_0 \le \mathrm{D}$, and both ends are $\log_2 n \pm O(1)$.
Tseitin search on an expander relation \(\Theta(n)\) Between $\mathrm{R} = \Theta(n)$ and $\mathrm{D} = \Theta(n)$.
Inner product mod 2 total \(n\) Sandwiched: $\mathrm{s}(f) \le \mathrm{R}_{0}(f) \le \mathrm{D}(f)$, with both ends $n$ here.
Minsky-Papert one-in-a-box total \(\Theta(m^3) = \Theta(N)\) Squeezed between $\mathrm{R} = \Theta(N)$ and $\mathrm{D} = N$.
Sink of a tournament total \(\Theta(m) = \Theta(\sqrt N)\) Sandwiched: $\mathrm{bs}(f) \le \mathrm{R}_{0}(f) \le \mathrm{D}(f)$, with both ends $\Theta(m) = \Theta(\sqrt N)$ here.
Scorpion graphs total \(\Theta(m)\) Sandwiched: $\mathrm{R}_{\varepsilon}(f) \le \mathrm{R}_{0}(f) \le \mathrm{D}(f)$, with $\mathrm{R} = \Theta(m)$ and $\mathrm{D} = O(m)$ here.
Graph connectivity total \(\Theta(m^2) = \Theta(N)\) Sandwiched between $\mathrm{R} = \Theta(N)$ and $\mathrm{D} = N$.
