\(\mathrm{C}^0(f)\)

0-certificate complexity

Largest minimal certificate over 0-inputs; the co-nondeterministic query complexity.

also written: co-nondeterministic query complexity, C_0

Definition

$\mathrm{C}^0(f) = \max_{x \in f^{-1}(0)} \mathrm{C}_x(f)$: the number of queries a nondeterministic algorithm needs to certify that $f(x) = 0$. Note the notation clash in the literature: some papers write $\mathrm{C}_0$ for this, others use $C^{(0)}$.

Basic facts

  • $\mathrm{D}(f) \le \mathrm{C}^0(f)\,\mathrm{C}^1(f)$; this is tight for $\mathrm{AND}\circ\mathrm{OR}$.
  • $\mathrm{C}(f) = \max(\mathrm{C}^0(f),\mathrm{C}^1(f))$.
  • $\mathrm{C}^0(f) = \mathrm{C}^1(\bar f)$.
  • $\mathrm{ndeg}(f) \le \mathrm{C}^1(f)$ and $\mathrm{rdeg}(f) \le \mathrm{C}(f)$.

Surjectivity total \(\Theta(n/\log n)\) putative Exactly $N$, the number of slots, which at $R = N/2$ is $n/\log_2 R = \Theta(n/\log n)$. Upper: a $0$-input misses some value $u$, and forcing $x_i \ne u$ costs a single bit per slot -- fix one position where $x_i$ and $u$ disagree. Lower: take the $0$-input in which every value except $u$ occurs at least twice; then for each slot $i$ the input obtained by rewriting $x_i$ to $u$ is surjective, so the certificate must fix a bit in every slot. Verified by exhaustive search at $R = 4$, $N = 8$, where $\max_x \mathrm{C}_x = 8 = N$ over all $0$-inputs. (An earlier version of this entry said $n$; that over-counts by a factor $\log R$ -- one does not have to pin down each $x_i$, only to keep it away from $u$.)

Minsky-Papert one-in-a-box total \(m^2 = N^{2/3}\) A $0$-certificate must exhibit an entirely empty box, and a box has $m^2$ bits. This is the asymmetry the whole function is built on.
Sink of a tournament total \(m\) putative To rule out every sink you must exhibit an out-edge for every vertex, and an oriented edge is an out-edge for exactly one of its endpoints -- so at least $m$ edges, and $m$ suffice (pick one out-edge per vertex; they are distinct). Note $\mathrm{C}^0 = m > m-1 = \mathrm{C}^1$, so the recorded $\mathrm{C} = \Theta(m)$ is exactly $m$.
Scorpion graphs total \(\Theta(m)\) putative Upper: $\mathrm{C}^0 \le \mathrm{D} = O(m)$. Lower: at the empty graph, refuting the triple $(\sigma,\tau,\beta)$ needs a queried edge in $\{\sigma\tau\} \cup \mathrm{star}(\beta)\setminus\{\beta\sigma\}$, so a $0$-certificate is a hitting set for that family; unless $P$ meets $\mathrm{star}(\beta)$ twice for nearly every $\beta$ it must contain a near-clique, and $\sum_\beta |P \cap \mathrm{star}(\beta)| = 2|P|$ then forces $|P| = \Omega(m)$; the empty graph's own optimum is exactly $m-1$ (a single star of absent pairs, isolating a vertex) for $5 \le m \le 8$, and that is where $\mathrm{C}_{\min}$ comes from. The maximum over $0$-inputs is larger: exhaustive search gives $\mathrm{C}^0 = 2m-4$ for $4 \le m \le 6$, matching $\mathrm{s}^0$ exactly, so $\mathrm{s}^0 = \mathrm{bs}^0 = \mathrm{C}^0$ and the extremal $0$-input is $K_{m-2}\sqcup K_2$ in all three.
Graph connectivity total \(\Theta(m^2)\) To certify disconnectedness you must exhibit a cut $(S,\bar S)$ with all $|S|(m-|S|)$ edges absent; the adversary makes $|S| = m/2$, so $\mathrm{C}^0 = \Theta(m^2)$.
