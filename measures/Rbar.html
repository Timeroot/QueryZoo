Measures › Randomized
\(\bar{\mathrm{R}}_{\varepsilon}(f)\)

Expected-cost randomized query complexity

Same as R_eps but the cost is the expected (not worst-case) number of queries.

also written: expected query complexity, average-depth randomized complexity

Definition

$\bar{\mathrm{R}}_\varepsilon(f) = \min_{A} \max_{x\in\mathrm{Dom}(f)} \mathbb{E}[\#\text{queries of }A\text{ on }x]$ over randomized algorithms $A$ that err with probability $\le\varepsilon$ on every $x$.

The distinction from $\mathrm{R}_\varepsilon$ matters:

  • $\bar{\mathrm{R}}_\varepsilon(f) \le \mathrm{R}_\varepsilon(f)$ always;
  • $\mathrm{R}_{\varepsilon'}(f) \le \bar{\mathrm{R}}_\varepsilon(f)/(\varepsilon'-\varepsilon)$ by Markov + truncation, so at constant error they agree up to constants;
  • at $\varepsilon = 1/2 - o(1)$ they can behave very differently, and Yao's question of whether $\bar{\mathrm{R}}_\varepsilon$ has a distributional characterisation has a positive answer for bounded error [Vereshchagin98] and a negative answer in the small-bias regime [BBGM22].

Parameters

\(\varepsilon\) (eps) default \(1/3\)

Detailed records: param-minimax · \(\text{Yao minimax: } \bar{\mathrm{R}}_\varepsilon(f) = \Theta\big(\max_\mu \mathrm{D}^{\mu}_{\varepsilon}(f)\big)\)

Basic facts

  • $\bar{\mathrm{R}}_0(f) = \mathrm{R}_0(f)$: the zero-error measure is by definition an expected-cost measure.
  • Yao (1977) asked for a distributional characterisation of $\bar{\mathrm{R}}_\varepsilon$; resolved positively for constant $\varepsilon$ and negatively for $\varepsilon = 1/2-o(1)$.
