\(\mathrm{cbs}(S)\)

Critical block sensitivity

Block sensitivity of a search problem: the adversary picks the input, but the algorithm picks which valid answer to commit to.

Degenerate for total functions and partial functions: Critical block sensitivity coincides with another measure there, so its row would only restate that one and the matrix omits it in those views. The collapse itself is recorded under equivalent measures below.

Definition

Defined for a search problem $S \subseteq \{0,1\}^n \times \mathcal{O}$. Call an input $x$ critical if it has exactly one valid answer, $|S(x)| = 1$. A solution function is any $s : \{0,1\}^n \to \mathcal{O}$ with $(x, s(x)) \in S$ for all $x$; for such an $s$, $\mathrm{bs}(s,x)$ is the ordinary block sensitivity of $s$ at $x$ (blocks whose flip changes the value of $s$, which is now not necessarily Boolean). Then $$\mathrm{cbs}(S) \ =\ \min_{s} \ \max_{x \text{ critical}} \ \mathrm{bs}(s,x).$$ The minimum over $s$ is what makes this a measure of the problem rather than of a particular algorithm: a search problem is only hard if every way of committing to answers is sensitive somewhere on a critical input.

Basic facts

  • $\mathrm{cbs}(f) = \mathrm{bs}(f)$ for Boolean $f$; the measure only says something new when an input has several valid answers.
  • Lifting: $\mathrm{R}^{cc}(S \circ g^n) = \Omega(\mathrm{cbs}(S))$ for a suitable constant-size gadget $g$ [GoosPitassi14]. This is the source of the tight monotone-circuit-depth and Cutting-Planes lower bounds obtained there.
  • For the false-clause search problem of a random $\Delta$-dense unsatisfiable $k$-CNF, $\mathrm{cbs} = \Omega(n)$; for the Tseitin search problem on a bounded-degree expander, $\mathrm{cbs} = \Omega(n)$ [GoosPitassi14].
  • The min over solution functions is essential: the maximum over $s$ can be large for trivially easy search problems.
  • The max over critical inputs is equally essential, and it cuts the other way: a search problem in which every input has at least two valid answers has no critical inputs at all, so the max is over the empty set and $\mathrm{cbs} = 0$. \(\mathrm{Find1}_{\ge n/2}\), \(\mathrm{ApproxHW}\) and \(\mathrm{AGREE}_n\) are of this kind, and there $\mathrm{cbs}$ certifies nothing whatsoever -- not a weak bound but no bound, so the relational column reads $\infty$ against it.

Equivalent / near-equivalent measures

  • \(\mathrm{bs}(f)\) $\mathrm{cbs}(f) = \mathrm{bs}(f)$ exactly: every input is critical and $s = f$ is forced GoosPitassi14
  • \(\mathrm{bs}(f)\) $\mathrm{cbs}(f) = \mathrm{bs}(f)$ on the promise too GoosPitassi14

Unstructured search (relation) relation \(n\) putative Exactly $n$, and for every solution function -- so the min over solution functions in the definition of \(\mathrm{cbs}(S)\) does nothing here. The all-zero input is critical: its only valid answer is $\bot$. Flipping any single coordinate $i$ turns it into $e_i$, whose only valid answer is $i \ne \bot$, so all $n$ singletons are sensitive blocks at $0^n$ whatever $s$ is; and $\mathrm{cbs} \le \mathrm{D} = n$. Compare $\mathrm{Q} = \Theta(\sqrt n)$: critical block sensitivity is a classical measure and sees none of the Grover speed-up.
FIND-1 under a density promise relation \(0\) putative Vacuously: \(\mathrm{cbs}(S)\) maximises over critical inputs, those with a unique valid answer, and this problem has none. A promise input has $|x| \ge n/2 \ge 2$ ones for $n \ge 4$, so every input admits at least two answers and the max is over the empty set. So critical block sensitivity -- the standard route to relational lower bounds -- says nothing whatever about a problem with $\mathrm{D} = n/2+1$. Contrast \(\mathrm{Search}(\varphi)\) and \(\mathrm{SEARCH}_n\), where the unique-answer inputs are exactly what carries the hardness.
Approximate Hamming weight relation \(0\) putative Vacuously: an input is critical for \(\mathrm{cbs}(S)\) when it has a unique valid answer, and here the valid answers at $x$ are all integers in $[\,|x|-\varepsilon n,\ |x|+\varepsilon n\,]$, an interval containing $\ge 2\varepsilon n \ge 2$ of them. So there are no critical inputs and the maximum in the definition is empty. Critical block sensitivity is blind to approximate-counting hardness, which is why the $\mathrm{psD}$ lower bound of [CDM23] needs a different technique.
Correlated-string search relation \(0\) putative No input has a unique valid answer -- there are $\binom{n}{\le n/2-\sqrt n}$ of them -- so there are no critical inputs and the maximum in the definition of \(\mathrm{cbs}(S)\) is empty. SearchCNF relation \(\Theta(1)\) putative For the random $\Delta$-dense formula this entry is otherwise about -- not $\Theta(n)$. Critical block sensitivity lower-bounds the randomized cost: let $s$ be the plurality output of a bounded-error algorithm, take a critical $x$ and $b$ disjoint blocks with $s(x^B) \ne s(x)$; an algorithm that never queries inside $B$ cannot answer whp at both $x$ and $x^B$, so it must enter each block with constant probability and $\mathrm{cbs} = O(\mathrm{R})$. Here $\mathrm{R} = \Theta(1)$. [ABK21lifting] give the same conclusion through $\mathrm{cbs} = O(\mathrm{CA})$ with $\mathrm{CA} = \Theta(1)$. The famous $\mathrm{cbs} = \Theta(n)$ belongs to the Tseitin contradiction on a bounded-degree expander [HuynhNordstrom12, GoosPitassi14], where an assignment can falsify a single vertex constraint and random sampling therefore fails -- see \(\mathrm{Ts}(G)\). Against $\mathrm{D} = \Theta(n)$ this makes the dense random formula an unbounded $\mathrm{D}$-vs-$\mathrm{cbs}$ separation rather than the $\Theta(1)$ ratio previously recorded. Welded trees relation \(\Theta(1)\) putative Contrast \(\mathrm{Ts}(G)\), where $\mathrm{cbs} = \Theta(n)$. Every input is critical -- the valid answer $\pi(\mathrm{EXIT})$ is unique -- so the solution function $s$ is forced and $\mathrm{cbs} = \max_x \mathrm{bs}(s,x)$. Let $B$ be a block whose flip changes the answer, and put $y = \pi(\mathrm{EXIT})$. In the modified instance $y$ is not the exit, so $y$ is either a degree-$3$ vertex or not a vertex at all; either way one of the nine cells $(y,c)$ has changed, so $B$ meets $\{(y,c)\}_{c=1}^{9}$. Disjoint blocks therefore number at most nine. At least one exists (rename the exit), so $\mathrm{cbs} = \Theta(1)$ -- which is the witness behind the recorded fact that $\mathrm{D}$ is unbounded in terms of $\mathrm{cbs}$ (\(\mathrm{D}(f)\) vs \(\mathrm{cbs}(S)\)).
Tseitin search on an expander relation \(\Theta(n)\) The theorem the measure exists for. Expansion is what forces it: any solution function must commit to a violated vertex, and flipping the edges along a path to a far-away vertex moves the violation, so no commitment is stable. Contrast \(\mathrm{Search}(\varphi)\) on a random dense formula, where a constant fraction of clauses is falsified, $\mathrm{R} = \Theta(1)$, and therefore $\mathrm{cbs} = \Theta(1)$ as well.
