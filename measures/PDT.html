\(\mathrm{D}^{\oplus}(f)\)

Parity decision tree complexity

Decision tree depth when each query may read the parity of an arbitrary subset of bits.

also written: D_parity, linear decision tree complexity over F_2

Definition

Each internal node is labelled by a set $S \subseteq [n]$ and branches on $\bigoplus_{i\in S} x_i$. $\mathrm{D}^{\oplus}(f)$ is the minimum depth. Clearly $\mathrm{D}^{\oplus}(f) \le \mathrm{D}(f)$, and $\mathrm{D}^{\oplus}$ can be exponentially smaller (e.g. $\mathrm{D}^\oplus(\mathrm{PARITY}_n)=1$). This is the query model tied to the log-rank conjecture through lifting.

Basic facts

  • $\mathrm{D}^{\oplus}(f) \ge \tfrac12\log_2 \mathrm{spar}(f)$: a depth-$d$ parity tree has $\le 2^d$ leaves, each the indicator of a coset of a codimension-$\le d$ subspace, whose Fourier support has size $\le 2^d$; so $\mathrm{spar}(f) \le 4^{\,d}$.
  • Whether the converse $\mathrm{D}^{\oplus}(f) = \mathrm{polylog}\,\mathrm{spar}(f)$ holds -- the log-rank conjecture for parity decision trees -- is a major open problem.
  • $\mathrm{D}^{\oplus}(f) = O(\sqrt{\mathrm{spar}(f)}\,\log \mathrm{spar}(f))$ is known for total $f$.

Bernstein-Vazirani partial \(n\) putative Parity queries buy nothing. A query on a set $S$ of positions returns $\bigoplus_{i \in S}\langle s, i\rangle = \langle s, \sum_{i \in S} i\rangle$ -- again a single linear functional of $s$ -- so $q$ queries reveal at most $q$ bits about the $n$-bit secret and $\mathrm{D}^{\oplus} \ge n$; and $\mathrm{D}^{\oplus} \le \mathrm{D} = n$. The Hadamard promise is precisely the fixed point of the parity model.
Unstructured search (relation) relation \(n\) putative Parity queries do not help. Along the branch where every answer is $0$, the queried sets $S_1,\dots,S_q$ are fixed; outputting $\bot$ is correct only if $0^n$ is the unique input consistent with those answers, i.e. only if $S_1,\dots,S_q$ span $\mathbb{F}_2^n$, forcing $q \ge n$. And $\mathrm{D}^{\oplus} \le \mathrm{D} = n$. Contrast $\mathrm{D}^{\oplus}(\mathrm{PARITY}) = 1$: what parity queries cannot do is locate a one.
FIND-1 under a density promise relation \(\Theta(n)\) putative At least $n/2$, so parity queries are as useless as ordinary ones. Answer $0$ to every query; after $q$ queries the consistent inputs form the linear space $W^{\perp}$, $\dim = n-q$, where $W$ is the span of the queried sets. A leaf that outputs $i$ must have $x_i = 1$ throughout $W^{\perp} \cap \{|x| \ge n/2\}$, but $V = W^{\perp} \cap \{x_i = 0\}$ has dimension $\ge n-q-1$, and any subspace of dimension $d$ contains a vector of weight $\ge d$ (sum the reduced-echelon basis: it is $1$ on all $d$ pivots). For $q \le n/2 - 1$ that vector satisfies the promise and refutes the leaf. And $\mathrm{D}^{\oplus} \le \mathrm{D} = n/2+1$. Against $\mathrm{R} = O(1)$ this is the same unbounded gap as for $\mathrm{D}$.
Approximate Hamming weight relation \(\Theta(n)\) putative Parity queries do not count either. After $q$ parity queries the consistent inputs form an affine space $A$ of dimension $n-q$; choosing $n-q$ free coordinates, every pattern on them occurs, so $A$ contains an input of weight $\le q$ (free part all $0$) and one of weight $\ge n-q$ (free part all $1$). A leaf can name one valid $w$ only if the weights inside $A$ span at most $2\varepsilon n$, forcing $n - 2q \le 2\varepsilon n$, i.e. $\mathrm{D}^{\oplus} \ge (1-2\varepsilon)n/2$. And $\mathrm{D}^{\oplus} \le \mathrm{D} = \Theta(n)$.
Gap-Majority partial \(\Theta(n)\) putative Parity queries are no better than plain ones. After $q$ parity queries the consistent inputs form an affine space $A$ of dimension $n-q$; picking $n-q$ free coordinates, $A$ contains an input of weight $\le q$ and one of weight $\ge n-q$. If $q < n/2-\delta n$ these are a $0$-input and a $1$-input of the promise, so no leaf can decide, giving $\mathrm{D}^{\oplus} \ge (1/2-\delta)n$; and $\mathrm{D}^{\oplus} \le \mathrm{D} = \Theta(n)$.
Gap-Majority at constant gap partial \(\Theta(n)\) putative Parity queries do not help: after $q < n/4$ of them the consistent affine space still contains inputs of both values. See \(\mathrm{GapMaj}^{\delta}_{n}\).
Surjectivity total \(\Theta(n)\) A depth-$t$ parity tree writes $f$ over $\mathbb{F}_2$ as a sum of products of at most $t$ affine forms, so $\deg_2\le\mathrm{D}^{\oplus}$; with $\deg_2=\Theta(n)$ and $\mathrm{D}^{\oplus}\le\mathrm{D}=n$ there is no room. Parity queries buy nothing on surjectivity.
Triangle finding total \(\Theta(m^2)\) $\deg_2\le\mathrm{D}^{\oplus}\le\mathrm{D}$: a depth-$t$ parity tree writes $f$ as a sum of products of at most $t$ affine forms over $\mathbb{F}_2$. With $\deg_2=\Theta(m^2)$ and $\mathrm{D}=\binom m2$ the two ends meet.
Fourier fishing relation \(\Omega(\log N),\ O(N)\) putative Upper: $\mathrm{D}^{\oplus}\le\mathrm{D}=N$. Lower: answer counting. For each $z$ the truth table $f=\chi_z$ has $z$ as its only valid answer, so a tree needs at least $N$ leaves and hence depth $\ge\log_2 N$. Whether parity queries actually help is open -- a parity of truth-table cells is not a Fourier coefficient.
Ordered search partial \(1\) putative One parity query. On the promise $x=0^k1^{n-k}$ the decision version is $\mathrm{OS}^{\oplus}=k\bmod 2=(n\bmod 2)\oplus\bigoplus_i x_i$, so the single query $\bigoplus_{i\in[n]}x_i$ settles it, against $\mathrm{D}=\lceil\log_2(n+1)\rceil$. The same identity is why $\deg=1$.
Tseitin search on an expander relation \(\Theta(\log n)\) putative Exponentially cheaper than $\mathrm{D}=\Theta(n)$. For a vertex set $S$, $\sum_{v\in S}(\chi(v)+\sum_{e\ni v}x_e)=\chi(S)+\sum_{e\in\partial S}x_e$ over $\mathbb{F}_2$, since interior edges are counted twice -- one parity query tells whether $S$ contains an odd number of violated vertices. Starting from $S=V$, which is odd because the total charge is odd, halving $S$ each time isolates a violated vertex in $\lceil\log_2|V|\rceil$ queries. Matching lower bound by answer counting: the violation vector is $Ax+\chi$, which ranges over all odd-weight vectors, so each single vertex $v$ is the unique answer for some input and the tree needs $|V|=\Theta(n)$ leaves.
Inner product mod 2 total \(\ge n/2 + 1\) The granularity of IP is exactly $2^{-n/2}$, so [ChistopolskayaPodolskii18] gives $\mathrm{D}^{\oplus} \ge n/2 + 1$. Upper bound: the trivial $n$. The factor $2$ is open as far as I know -- note $\mathrm{D}^{\oplus} \ge n/2$ also follows from bentness, since an affine subspace on which a bent function is constant has dimension at most $n/2$. Minsky-Papert one-in-a-box total \(N = m^3\) Pinned exactly: a depth-$d$ parity decision tree computes a function of $d$ linear forms, so $\deg_2(f) \le \mathrm{D}^{\oplus}(f) \le \mathrm{D}(f)$, and $\deg_2 = \mathrm{D} = N$ here. Parity queries are useless on a read-once AND-OR formula.
Sink of a tournament total \(\Theta(m) = \Theta(\sqrt N)\) putative Lower: $\mathrm{spar}(f) \le 4^{\mathrm{D}^{\oplus}(f)}$ with $\mathrm{spar} = \Theta(m2^m)$ gives $\mathrm{D}^{\oplus} \ge (m-1)/2$. Upper: $\mathrm{D}^{\oplus} \le \mathrm{D} = O(m)$. Parity queries buy nothing, which is the query-level shadow of the [CMS19] refutation: $\mathrm{SINK}$ has tiny spectral norm yet its parity decision trees are as deep as its ordinary ones.
Graph connectivity total \(\Theta(m^2) = \Theta(N)\) Sandwiched: $\deg_2(f) \le \mathrm{D}^{\oplus}(f) \le \mathrm{D}(f)$, with $\deg_2 = \lfloor m^2/4\rfloor$ and $\mathrm{D} = N$ here. Parity queries save at most the factor $2$ that $\mathbb{F}_2$-degree already saves -- connectivity is evasive up to a constant even for parity decision trees.
