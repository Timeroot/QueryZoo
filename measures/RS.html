\(\mathrm{RS}(f)\)

Sabotage complexity

Randomized cost of finding a "sabotaged" (damaged) input bit; the first measure with perfect composition.

Definition

Define the sabotaged problem $f_{\mathrm{sab}}$: the input is a partial assignment with some coordinates set to $\ast$ such that the $\ast$'s genuinely matter (the value of $f$ is not determined), and the goal is to find one $\ast$. $\mathrm{RS}(f)$ is the bounded-error randomized query complexity of $f_{\mathrm{sab}}$.

Basic facts

  • Formally $\mathrm{RS}(f) := \mathrm{R}_0(f_{\mathrm{sab}})$; using $\mathrm{R}$ instead of $\mathrm{R}_0$ changes nothing up to constants [BenDavidKothari18, Def. 10].
  • $\mathrm{RS}(f\circ g) \ge \mathrm{RS}(f)\,\mathrm{RS}(g)$ -- perfect composition [BenDavidKothari18, Thm 19].
  • $\mathrm{R}(f\circ g^n) = \Omega(\mathrm{R}(f)\,\mathrm{RS}(g))$ [BenDavidKothari18, Thm 21].
  • $\mathrm{R}_\varepsilon(f) \ge \bar{\mathrm{R}}_\varepsilon(f) \ge (1-2\varepsilon)\,\mathrm{RS}(f)$ [BenDavidKothari18, Thm 12].
  • Quadratically tight for total $f$: $\mathrm{R}(f) = O(\mathrm{RS}(f)^2\log \mathrm{RS}(f))$ [BenDavidKothari18, Thm 32].
  • $\mathrm{RS}$ can be quadratically larger than the partition bound, and $\mathrm{RS}(f) = \tilde\Omega(\mathrm{Q}(f)^{2.5})$ for some total $f$ [BenDavidKothari18, Thm 30].
  • $\mathrm{RS}(g) = \tilde\Omega(\mathrm{D}^{\mathrm{prod}}(g))$ for total $g$, and the gap is polynomial (NAND-tree) [Sanyal24].
  • The quadratic tightness above is total-only, and badly so. On partial functions $\mathrm{R}$ is unbounded in terms of $\mathrm{RS}$: any promise whose two sides are far apart in Hamming distance has $\mathrm{RS} = O(1)$ whatever its randomized complexity, because every sabotaged input is then riddled with stars. The collision problem is the clean instance -- $\mathrm{RS}(\mathrm{COL}_n) = \Theta(1)$ against $\mathrm{R} = \Theta(\sqrt n)$ [BenDavidKothari18, Sec. 1.4]. See \(\mathrm{COL}_n\).
  • $\bar{\chi}(g) = \Omega(\mathrm{RS}(g))$ for all partial $g$ [GLSS19, Thm 7]; the same collision witness makes that gap unbounded. Repairing the partial-function collapse is what $\chi$, $\bar\chi$ and $\mathrm{LR}$ are for: each is $\Omega(\sqrt{\mathrm{R}})$ even off the promise, and $\mathrm{RS}$ is not.
  • Total functions now separate sabotage and randomized complexity by $\Omega(\log N)$ [Meiburg26composition]; \(P_q\) is a witness. Conflict and sabotage are incomparable on total functions: the opposite directions use that family and \(\mathrm{AND}_n \circ \mathrm{OR}_n\).

Collision problem partial \(\Theta(1)\) The reason sabotage complexity is a total-function measure. A one-to-one table and a two-to-one table can agree on at most one point of each of the $n/2$ pairs, so they differ in $\ge n/2$ of the $n$ cells (the same counting as $\mathrm{CG}^{\mathrm{pub}}$ above). Every sabotaged input therefore carries $\ge n/2$ stars, and one uniformly random query finds a star with probability $\ge 1/2$: $\mathrm{RS} \le 2$. From below $\mathrm{RS} \ge \mathrm{CA} = \Omega(1)$. [BenDavidKothari18, Sec. 1.4] state it exactly so -- "any sabotaged input to the collision problem has at least half the bits sabotaged making $\mathrm{RS}(f) = O(1)$, but $\mathrm{R}(f) = \Omega(\sqrt n)$" -- as the reason their quadratic upper bound $\mathrm{R} = O(\mathrm{RS}^2\log\mathrm{RS})$ has to assume totality.
