\(\mathrm{N}_{p}(f)\)

Noisy decision tree complexity

Number of queries when every query answer is independently flipped with probability p.

also written: noisy query complexity (FRPU model), noisy oracle complexity

Definition

In the model of Feige-Raghavan-Peleg-Upfal each query (repeats allowed) returns $x_i \oplus \eta$ where $\eta = 1$ with probability $p \in (0,1/2)$ independently each time. $\mathrm{N}_p(f)$ is the least number of queries needed to output $f(x)$ with error $\le 1/3$.

This is a different notion from \(\mathrm{noisyR}(f)\): here the noise rate is imposed by the model, and repetition is the only way to reduce it, whereas in the Ben-David-Blais model the algorithm chooses the bias and pays for it.

Parameters

\(p\) (p) default \(constant in (0,1/2)\)

per-query flip probability

For constant $p$, changing $p$ changes $\mathrm{N}_p$ by only a constant factor (each "reliable" bit costs $\Theta(\log(1/\delta)/(1-2p)^2)$ repetitions). The interesting dependence is on the target error and on $n$.

Detailed records: \(\mathrm{N}_{p}(f) \text{ as a function of the flip probability } p\)

Basic facts

  • $\mathrm{N}_p(f) = O(\mathrm{R}(f)\log \mathrm{R}(f))$ always (amplify each query by $O(\log \mathrm{R})$ repetitions and union bound).
  • $\mathrm{N}_p(\mathrm{PARITY}_n) = \Theta(n\log n)$ [FRPU94] -- the log factor is necessary, giving a genuine separation from $\mathrm{R}$.
  • Average-case/Fourier lower bound: $\mathrm{N}_p(f) = \Omega\!\big(\sum_S |\hat f(S)|^2 |S| \log|S|\big)$-flavoured bounds [Evans-Pippenger].
  • $\mathrm{N}_p(f) = \Omega(\mathrm{I}(f)\log \mathrm{I}(f))$ for every total $f$ [GLX26noisy] -- the first general lower bound beyond the trivial $\mathrm{N}_p(f) = \Omega(\mathrm{R}(f))$, and tight at PARITY.
  • Almost all $f$ need $\Omega(n\log n)$ noisy queries [Reischuk-Schmeltz].
  • Quantum contrast: the robust quantum query complexity of PARITY is $\Theta(n)$ -- no log factor [BNRdW05].
