\(\mathrm{Q}_{\mathrm{E}}(f)\)

Exact quantum query complexity

Number of queries of a quantum algorithm that outputs f(x) with probability 1.

also written: Q_0 in some papers (careful!), zero-error-with-certainty quantum complexity

Definition

$\mathrm{Q}_{\mathrm{E}}(f) = \mathrm{Q}_0(f)$ in the "always right" sense: the algorithm must output the correct answer with certainty. Note the notational hazard: some authors use $\mathrm{Q}_0$ for the Las Vegas (zero-error-but-may-abort) version, which is \(\mathrm{Q}_{0}(f)\) here.

Basic facts

  • $\deg(f) \le 2\,\mathrm{Q}_{\mathrm{E}}(f)$ [BBCMdW01].
  • $\mathrm{Q}_{\mathrm{E}}(\mathrm{PARITY}_n) = \lceil n/2\rceil$: the only known factor-2 speedup style behaviour for total functions.
  • First superlinear-advantage total function: $\mathrm{Q}_{\mathrm{E}}(f) = O(\mathrm{D}(f)^{0.8675\ldots})$ [Ambainis13], giving the $1.15$ exponents in the $\mathrm{Q}_{\mathrm{E}}$ column.
  • It is open whether $\mathrm{Q}_{\mathrm{E}}(f) = O(\deg(f))$ for total $f$ [BdW02, Open problem 4].

Parity-labelled FIND-1 partial \(1\) putative One query, with certainty. Prepare $|\psi\rangle = (n/2)^{-1/2}\sum_{i \text{ odd}}|i\rangle$ and apply the phase oracle $|i\rangle \mapsto (-1)^{x_i}|i\rangle$. On a $0$-input every odd coordinate is $0$, so the state is unchanged; on a $1$-input exactly $n/4$ of the $n/2$ odd coordinates carry a $-1$, so the state is orthogonal to $|\psi\rangle$. The projective measurement $\{|\psi\rangle\langle\psi|,\, I - |\psi\rangle\langle\psi|\}$ then answers with probability $1$ either way. This is \(\mathrm{DJ}_n\) run on the odd half, and it is why the promise fixes $|x| = n/4$: half of the odd coordinates, so the $1$-case is exactly balanced. Contrast \(\mathrm{GapMaj}^{\delta}_{n}\) and \(\mathrm{Find1}_{\ge n/2}\), where exactness costs $\Theta(n)$.

The usual $\mathrm{Q}_{\mathrm{E}} \ge \deg/2$ route is unavailable because $\deg(\mathrm{DIST}^k)$ is itself not recorded.
Recursive Fourier sampling partial \(2^\ell\) One level costs two queries by the Bernstein-Vazirani kickback trick, and the recursion is exact: [Aaronson03rfs, Lem. 1] puts the language version in $\mathrm{EQP}^A$; [BernsteinVazirani97, Thm. 8.4.3] gives a polynomial-time quantum machine accepting with probability $1$, from the recursion $T(n) \le \mathrm{poly}(n) + 4T(n/2)$. Aaronson03rfs BernsteinVazirani97
Welded trees relation \(O(n^{1.5}\log n)\) [LiLiLuo24, §5, Alg. 2]: run the plain coined quantum walk for a classically precomputable number of steps, then exact amplitude amplification. Zero error -- one of very few exponential $\mathrm{Q}_E$-vs-$\mathrm{R}$ separations known. Their bounded-error Alg. 1 uses $O(n^2\log n)$ queries. LiLiLuo24
Local search on the hypercube relation \(\Omega(2^{n/3}n^{1/6}),\ O(2^n/\sqrt n)\) $\mathrm{Q}\le\mathrm{Q}_0\le\mathrm{Q}_{\mathrm{E}}\le\mathrm{D}$, with $\mathrm{Q}=\Theta(2^{n/3}n^{1/6})$ and $\mathrm{D}=\Theta(2^n/\sqrt n)$. Nothing is known about exact local search: even the classical deterministic upper bound is the only ceiling available.
Local search on the grid relation \(\Omega(k^{d/3}),\ O(k^{d-1})\ (d \ge 6)\) $\mathrm{Q}\le\mathrm{Q}_0\le\mathrm{Q}_{\mathrm{E}}\le\mathrm{D}$, with $\mathrm{Q}=\Theta(k^{d/3})$ and $\mathrm{D}=\Theta(k^{d-1})$.
Ordered search partial \(\Theta(\log n)\) Upper $0.390\log_2 n$: [CCKS25] show every bounded-error $k$-query algorithm can be made translation-invariant with no workspace, and an LP search then finds an exact $5$-query algorithm for lists of length $7265$. Earlier exact algorithms: $0.526\log_2 n$ ($3$ queries, $52$ items) [FGGS99invariant], $0.433\log_2 n$ ($4$ queries, $605$ items) [CLP07]. Lower: $\mathrm{Q}_E \ge \mathrm{Q} \ge \tfrac1\pi(\ln n - 1)$. CCKS25 HNS02
Tseitin search on an expander relation \(O(n)\) $\mathrm{Q}_{\mathrm{E}}\le\mathrm{D}=\Theta(n)$. Reading every edge determines the whole violation vector, and nothing better is known exactly: the Grover algorithm behind $\mathrm{Q}=O(\sqrt n)$ has one-sided error.
Inner product mod 2 total \(\Theta(n)\) Sandwiched: $\mathrm{Q}_E \ge \deg/2 = n/2$ and $\mathrm{Q}_E \le \mathrm{D} = n$. (With a parity oracle the answer would be $m+1$ or so; see $\mathrm{D}^{\oplus}$ below.)
Minsky-Papert one-in-a-box total \(N = m^3\) Sandwiched exactly: $\deg(f) \le \mathrm{Q}_{\mathrm{E}}(f) \le \mathrm{D}(f)$, and both ends are $N = m^3$ here. Exact quantum computation buys nothing on a read-once AND-OR formula, while bounded error buys the full quadratic $\Theta(\sqrt N)$.
Sink of a tournament total \(\Theta(m) = \Theta(\sqrt N)\) Sandwiched: $\deg/2 = (m-1)/2 \le \mathrm{Q}_{\mathrm{E}} \le \mathrm{D} = O(m)$. Unlike the bounded-error $\mathrm{Q}$, which is open between $\Omega(\sqrt m)$ and $O(m)$, the exact value is pinned.
Scorpion graphs total \(\Theta(m) = \Theta(\sqrt N)\) Sandwiched: $\deg/2 = (3m-6)/2 \le \mathrm{Q}_{\mathrm{E}} \le \mathrm{D} = O(m)$.
Graph connectivity total \(\Theta(m^2) = \Theta(N)\) Sandwiched between $\deg/2 = N/2$ and $\mathrm{D} = N$. Exact quantum computation buys at most a factor $2$ on connectivity, while bounded error buys the $\Theta(N^{3/4})$ of \(\mathrm{Q}_{\varepsilon}(f)\).
Ben-David–Kothari championship function total \(\Theta(n\log n)\) v3 concurrent-work discussion extends the championship algorithm to exact queries and gives a matching restriction. AIK26
Ambainis–Iraids–Kokainis certificate cheat sheet total \(\Theta(n\log^2 n)\) Theorem 2.3; exact amplification and the count-field restriction. AIK26
