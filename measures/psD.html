\(\mathrm{psD}(S)\)

Pseudo-deterministic query complexity

Randomized cost of a search algorithm that must output the same canonical answer with high probability on every input.

also written: pseudodeterministic decision tree complexity, reproducible randomized complexity

Degenerate for total functions and partial functions: Pseudo-deterministic query complexity coincides with another measure there, so its row would only restate that one and the matrix omits it in those views. The collapse itself is recorded under equivalent measures below.

Definition

For a relation $S \subseteq \{0,1\}^n \times \mathcal{O}$, a pseudo-deterministic algorithm is a randomized decision tree $A$ together with a canonical solution function $s : \{0,1\}^n \to \mathcal{O}$ with $(x, s(x)) \in S$, such that $$\Pr[A(x) = s(x)] \ \ge\ 2/3 \quad\text{for every } x .$$ $\mathrm{psD}(S)$ is the least worst-case cost of such an $A$. It interpolates between $\mathrm{R}$ and $\mathrm{D}$: a deterministic algorithm is trivially pseudo-deterministic, and a pseudo-deterministic algorithm is randomized. This is the measure that makes the relational setting interesting: for Boolean-valued $f$ it collapses, $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$, because the canonical answer is forced.

Basic facts

  • $\mathrm{R}(S) \le \mathrm{psD}(S) \le \mathrm{D}(S)$.
  • $\mathrm{D}(S) = O(\mathrm{psD}(S)^3)$ for total search problems [CDM23], improving the quartic bound of [GGR13].
  • $\mathrm{R}$ and $\mathrm{psD}$ are exponentially separated: for the approximate-Hamming-weight relation $\mathrm{ApproxHW}$, $\mathrm{R} = O(1)$ while $\mathrm{psD} = \Omega(n)$ [CDM23]; and $\mathrm{psD}(\mathrm{SearchCNF}) = \Omega(n^{1/3})$ for random $k$-CNFs [CDM23], $\Omega(\sqrt{n})$ in the setting of [GIPS21].
  • In the zero-error average-case setting, deterministic, randomized and pseudo-deterministic complexity all coincide [GIPS21].

Equivalent / near-equivalent measures

  • \(\mathrm{R}_{\varepsilon}(f)\) $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ for Boolean-valued $f$: the canonical answer is forced, so reproducibility is free GGR13
  • \(\mathrm{R}_{\varepsilon}(f)\) $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ on the promise as well -- the collapse only needs the answer to be unique GGR13

Local search on the hypercube relation \(\Omega(2^{n/2}\sqrt n),\ O(2^n/\sqrt n)\) Only the generic $\mathrm{R} \le \mathrm{psD} \le \mathrm{D}$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)), and here the two ends are quadratically apart, so this is one of the natural places to look for a genuine pseudo-deterministic separation: a randomized algorithm may return any local minimum, but committing in advance to which one looks much closer to the deterministic problem of finding a canonical minimum.
Local search on the grid relation \(\Omega(k^{d/2}),\ O(k^{d-1})\ (d \ge 4)\) Only the generic $\mathrm{R} \le \mathrm{psD} \le \mathrm{D}$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)). The window is a factor $k^{d/2-1}$ wide, and unlike \(\mathrm{LS}(\{0,1\}^n)\) it stays wide for every fixed $d \ge 4$, so the grid is the cleaner family to ask the pseudo-deterministic question on: is there a canonical local minimum findable in $\tilde O(k^{d/2})$ randomized queries?
Fourier fishing relation \(\Omega(N/\log N),\ O(N)\) Only the generic $\mathrm{R} \le \mathrm{psD} \le \mathrm{D}$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)), and the window is the same $\log N$ that is open for $\mathrm{R}$. Pseudo-determinism cannot help much here because $\mathrm{R}_0 = \Theta(N)$ already pins the top of the range.
Tseitin search on an expander relation \(\Theta(n)\) putative At least $\mathrm{R} = \Theta(n)$ and at most $\mathrm{D} = \Theta(n)$, so pseudo-determinism is free here. Contrast \(\mathrm{Search}(\varphi)\) and \(\mathrm{ApproxHW}\), where it is exactly the expensive part.
Inner product mod 2 total \(\Theta(n)\) For a Boolean function the canonical answer is forced, so $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)); here $\mathrm{R} = \Theta(n)$.
Minsky-Papert one-in-a-box total \(\Theta(m^3) = \Theta(N)\) For a Boolean function the canonical answer is forced, so $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)); here $\mathrm{R} = \Theta(N)$.
Sink of a tournament total \(\Theta(m) = \Theta(\sqrt N)\) For a Boolean function the canonical answer is forced, so $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)).
Scorpion graphs total \(\Theta(m)\) For a Boolean function the canonical answer is forced, so $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)); here $\mathrm{R} = \Theta(m)$.
Graph connectivity total \(\Theta(m^2) = \Theta(N)\) For a Boolean function the canonical answer is forced, so $\mathrm{psD}(f) = \Theta(\mathrm{R}(f))$ (\(\mathrm{psD}(S)\) vs \(\mathrm{R}_{\varepsilon}(f)\)); here $\mathrm{R} = \Theta(m^2)$.

Defined for

  • Total functions degenerate
    For total (or partial) Boolean functions $\mathrm{psD} = \Theta(\mathrm{R})$: there is only one correct answer, so reproducibility is free.
  • Partial functions degenerate
    Same collapse as for total functions.
  • Relations yes
    The natural home of this measure. Only interesting when a single input admits several valid outputs.
