\(\mathrm{Q}_{\varepsilon}(f)\)

Bounded-error quantum query complexity

Number of applications of the phase/bit oracle O_x needed to compute f with error <= eps.

also written: Q_2(f), quantum decision tree complexity

Definition

A $T$-query quantum algorithm is $U_T O_x U_{T-1}\cdots O_x U_0 |0\rangle$, measured at the end; $O_x$ maps $|i,b\rangle\mapsto|i,b\oplus x_i\rangle$. $\mathrm{Q}_\varepsilon(f)$ is the least $T$ such that some algorithm outputs $f(x)$ with probability $\ge 1-\varepsilon$ for all $x$ in the domain. Unadorned $\mathrm{Q}(f):=\mathrm{Q}_{1/3}(f)$.

Parameters

\(\varepsilon\) (eps) default \(1/3\)range \([0, 1/2)\)

$\mathrm{Q}_\varepsilon(f) = O(\mathrm{Q}(f)\log(1/\varepsilon))$ by majority voting. For decision problems the $\log(1/\varepsilon)$ is sometimes removable via amplitude amplification when the algorithm has one-sided structure. In the small-bias regime $\varepsilon = 1/2-\gamma$ one has $\mathrm{Q}(f) = O(\gamma^{-1}\mathrm{Q}_{1/2-\gamma}(f))$ -- note $\gamma^{-1}$, not $\gamma^{-2}$: amplitude amplification is quadratically better than classical majority voting, which is the source of several quantum/classical gaps.

Detailed records: \(\mathrm{Q}_{\varepsilon}(f) \text{ as } \varepsilon\to 0\)

Basic facts

  • $\widetilde{\deg}(f) \le 2\,\mathrm{Q}(f)$ [BBCMdW01].
  • $\mathrm{D}(f) = O(\mathrm{Q}(f)^4)$ for total $f$ [ABKRT21], improving $O(\mathrm{Q}^6)$; matching separation $\mathrm{D}=\tilde\Omega(\mathrm{Q}^4)$ [ABBLSS17], so the exponent is 4, settled.
  • $\mathrm{R}(f) \le \mathrm{D}(f) = O(\mathrm{Q}(f)^4)$ for total $f$; best known separation $\mathrm{R}=\tilde\Omega(\mathrm{Q}^3)$ [BansalSinha21, SSW21], so the $\mathrm{R}$-vs-$\mathrm{Q}$ exponent lies in $[3,4]$.
  • Quantum query complexity composes perfectly: $\mathrm{Q}(f\circ g) = \Theta(\mathrm{Q}(f)\mathrm{Q}(g))$.
  • For partial functions the gap with $\mathrm{R}$ is unbounded: $\mathrm{Q}=O(1)$ vs $\mathrm{R}=\tilde\Omega(n^{1-1/2k})$; exponential for Simon's problem.

Equivalent / near-equivalent measures

  • \(\mathrm{Adv}^{\pm}(f)\) $\mathrm{Q}(f) = \Theta(\mathrm{Adv}^{\pm}(f))$ for all partial Boolean $f$ Reichardt11 LMRSS11

Sink of a tournament total \(\Omega(\sqrt m),\ O(m)\) Open, and the same gap as $\widetilde{\deg}$. Lower: $\mathrm{Q} \ge \widetilde{\deg}/2 = \Omega(\sqrt{\mathrm{bs}}) = \Omega(\sqrt m) = \Omega(N^{1/4})$. Upper: $\mathrm{Q} \le \mathrm{D} = O(m)$, and the obvious quantum algorithm does no better -- amplitude amplification over the $m$ candidate sinks, each checked by a Grover search for an out-edge, costs $O(\sqrt m \cdot \sqrt m) = O(m)$, exactly what candidate elimination already gives classically.
