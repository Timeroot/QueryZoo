\(\overline{\mathrm{prt}}_{\varepsilon}(f)\)

Relaxed partition bound

The partition bound with the "fires with probability exactly 1" constraint relaxed to "at most 1"; weaker, but unlike prt it lower-bounds information complexity.

also written: relaxed partition bound, \mathrm{prt}^{\ast}

Definition

Take the LP of the partition bound and relax the completeness constraint from an equality to an inequality: $$\min \sum_{A,z} w_{A,z}\, 2^{|A|} \quad\text{s.t.}\quad \sum_{A \ni x} w_{A,f(x)} \ge 1-\varepsilon \ \text{ and }\ \sum_{A \ni x,\, z} w_{A,z} \;\le\; 1 \qquad \text{for every } x ,$$ and again put $\overline{\mathrm{prt}}_\varepsilon(f) := \log_2(\text{optimum})$. The only change is the second constraint: $=1$ has become $\le 1$. In the zero-communication reading, the prover is now allowed to abort: the probability that some subcube fires may be anywhere in $[1-\varepsilon, 1]$ instead of being exactly $1$ on every input. The relaxation is genuine but not vacuous -- the two constraints together still force $\sum_{A\ni x} w_{A,z} \le \varepsilon$ for every wrong answer $z \ne f(x)$, so e.g. one cannot simply buy the whole cube twice, once under each label.

The bound was defined for communication complexity by [KLLRX15, Def. 3.2], who write the objective as $1/\eta$ where $\eta$ is the non-abort probability, normalise $\sum_{R,z} p_{R,z} = 1$, and impose correctness only on average under an input distribution $\mu$ before taking $\overline{\mathrm{prt}}_\varepsilon = \max_\mu \overline{\mathrm{prt}}^{\,\mu}_\varepsilon$ (the averaging is what lets them handle promise problems). The display above is the query analogue in the subcube dictionary, with correctness kept pointwise.

Parameters

\(\varepsilon\) (eps) default \(1/3\)

Basic facts

  • $\overline{\mathrm{prt}} \le \mathrm{prt} \le 2\,\mathrm{R}$: enlarging the feasible region can only lower the optimum.
  • Why the relaxation was invented: $\overline{\mathrm{prt}}$ lower-bounds information complexity, $\mathrm{prt}$ is not known to [KLLRX15, Thm 1.1]. The proof compresses a protocol leaking $I$ bits into a zero-communication protocol with non-abort probability $2^{-O(I)}$, and one cannot make that probability come out exactly equal on every input -- hence the inequality.
  • In communication complexity it sits above the smooth rectangle bound, $\mathrm{srec}^z_\varepsilon \le \overline{\mathrm{prt}}_\varepsilon \le \mathrm{prt}_\varepsilon$ [KLLRX15, Lem. 3.3], and therefore also above corruption, $\gamma_2$ and discrepancy.
  • In the query setting every lower bound the partition bound subsumes survives the relaxation -- see the $\mathrm{bs} \to \overline{\mathrm{prt}}$ record for the argument -- so $\overline{\mathrm{prt}}$ is pinned to $\Theta(\mathrm{R})$ on all the usual functions, exactly like $\mathrm{prt}$.
  • For total search problems there is an exponential separation between quantum information complexity (communication) and the relaxed partition bound [BenDavidKundu24search]; even the randomized-vs-$\overline{\mathrm{prt}}$ separation was previously unknown for total search problems.
